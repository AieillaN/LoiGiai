BÀI 2: TÍCH PHÂN (PHẦN TIẾP THEO) – ĐỀ A

Lời giải chi tiết từng bước, định dạng trực quan theo phương pháp chuẩn sách giáo khoa, tích hợp đầy đủ các bài toán ứng dụng thực tế liên môn và bài tập phân hóa theo nhóm năng lực.

I

PHẦN 1: CÁC BÀI TẬP TRÊN LỚP

DẠNG 1: TÍCH PHÂN HÀM SỐ CHỨA DẤU GIÁ TRỊ TUYỆT ĐỐI

Cách 1: Đưa trị tuyệt đối ra ngoài

1. Cho $f(x)=0$ tìm các nghiệm $x_1 < x_2 < \dots < x_n \in [a;b]$.
2. Chèn cận và đưa dấu trị tuyệt đối ra ngoài từng khoảng (do trên mỗi khoảng nghiệm $f(x)$ không đổi dấu):

$$I = \left|\int_{a}^{x_1} f(x)dx\right| + \left|\int_{x_1}^{x_2} f(x)dx\right| + \dots + \left|\int_{x_n}^{b} f(x)dx\right|$$
Cách 2: Xét dấu trực tiếp

1. Lập bảng xét dấu của biểu thức $f(x)$ trên đoạn $[a;b]$.
2. Dùng định nghĩa $|A| = \begin{cases} A & \text{khi } A \ge 0 \\ -A & \text{khi } A < 0 \end{cases}$ để khử dấu trị tuyệt đối trên từng khoảng rồi tính từng tích phân.

Ví Dụ Mẫu

Tính tích phân: $A = \int_{-2}^{2} |x^2 - 1| \, dx$

Kết quả: $4$

Bước 1: Xét phương trình hoành độ $x^2 - 1 = 0 \iff x = \pm 1$. Cả hai nghiệm $-1; 1$ đều thuộc $[-2; 2]$.

Bước 2: Xét dấu biểu thức $x^2 - 1$ trên đoạn $[-2; 2]$:

  • Trên $[-2; -1]$ và $[1; 2]$: $x^2 - 1 \ge 0 \implies |x^2 - 1| = x^2 - 1$.
  • Trên $[-1; 1]$: $x^2 - 1 \le 0 \implies |x^2 - 1| = -(x^2 - 1) = 1 - x^2$.

Bước 3: Tách cận và tính nguyên hàm:

$$A = \int_{-2}^{-1} (x^2 - 1)dx + \int_{-1}^{1} (1 - x^2)dx + \int_{1}^{2} (x^2 - 1)dx$$ $$= \left[\frac{x^3}{3} - x\right]_{-2}^{-1} + \left[x - \frac{x^3}{3}\right]_{-1}^{1} + \left[\frac{x^3}{3} - x\right]_{1}^{2} = \frac{4}{3} + \frac{4}{3} + \frac{4}{3} = 4$$
Bài 1

Tính các tích phân sau:

a) $I_a = \int_{0}^{3} |x^2 - 2x| \, dx$

• Giải phương trình: $x^2 - 2x = 0 \iff x = 0$ hoặc $x = 2 \in [0; 3]$.

• Phá dấu giá trị tuyệt đối:

$$I_a = \int_{0}^{2} (2x - x^2)dx + \int_{2}^{3} (x^2 - 2x)dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 + \left[\frac{x^3}{3} - x^2\right]_2^3 = \frac{4}{3} + \frac{4}{3} = \frac{8}{3}$$
b) $I_b = \int_{-2}^{1} |x^3 + x^2 - 2x| \, dx$

• Phương trình $x^3 + x^2 - 2x = x(x-1)(x+2) = 0$ có các nghiệm $x \in \{-2; 0; 1\}$.

• Xét dấu trên $[-2; 0]$ ta có biểu thức $\ge 0$; trên $[0; 1]$ biểu thức $\le 0$.

$$I_b = \int_{-2}^{0} (x^3 + x^2 - 2x)dx - \int_{0}^{1} (x^3 + x^2 - 2x)dx$$ $$= \left[\frac{x^4}{4} + \frac{x^3}{3} - x^2\right]_{-2}^0 - \left[\frac{x^4}{4} + \frac{x^3}{3} - x^2\right]_0^1 = \left(0 - \left(-\frac{8}{3}\right)\right) - \left(-\frac{5}{12} - 0\right) = \frac{8}{3} + \frac{5}{12} = \frac{37}{12}$$
c) $I_c = \int_{-1}^{2} |x^3 - 3x + 2| \, dx$

• Phân tích nhân tử: $x^3 - 3x + 2 = (x - 1)^2(x + 2)$.

• Với mọi $x \in [-1; 2]$, ta có $(x - 1)^2 \ge 0$ và $x + 2 \ge 1 > 0 \implies x^3 - 3x + 2 \ge 0$ không âm trên toàn đoạn.

$$I_c = \int_{-1}^{2} (x^3 - 3x + 2)dx = \left[\frac{x^4}{4} - \frac{3x^2}{2} + 2x\right]_{-1}^2 = 2 - \left(-\frac{13}{4}\right) = \frac{21}{4}$$
d) $I_d = \int_{1}^{2026} \sqrt{x^2 - 6x + 9} \, dx$

• Nhận dạng hằng đẳng thức: $\sqrt{x^2 - 6x + 9} = \sqrt{(x - 3)^2} = |x - 3|$. Nghiệm chia đoạn là $x = 3 \in [1; 2026]$.

$$I_d = \int_{1}^{3} (3 - x)dx + \int_{3}^{2026} (x - 3)dx = \left[3x - \frac{x^2}{2}\right]_1^3 + \left[\frac{(x - 3)^2}{2}\right]_3^{2026} = 2 + \frac{2023^2}{2} = \frac{4092533}{2}$$
Bài 2 (Nhóm 1)

Tính các tích phân nâng cao

a) $I = \int_{-3}^{5} (|x + 2| - |x - 2|) \, dx$

Tách miền qua hai điểm gãy $x = -2$ và $x = 2$ thuộc $(-3; 5)$:

  • Trên $[-3; -2]$: $|x + 2| - |x - 2| = -(x + 2) - [-(x - 2)] = -4$.
  • Trên $[-2; 2]$: $|x + 2| - |x - 2| = (x + 2) - [-(x - 2)] = 2x$.
  • Trên $[2; 5]$: $|x + 2| - |x - 2| = (x + 2) - (x - 2) = 4$.
$$I = \int_{-3}^{-2} (-4)dx + \int_{-2}^{2} 2x dx + \int_{2}^{5} 4 dx = -4(1) + \left[x^2\right]_{-2}^2 + 4(3) = -4 + 0 + 12 = 8$$
b) $I = \int_{0}^{3} \sqrt{x^3 - 2x^2 + x} \, dx$

Biến đổi dưới căn với $x \ge 0$: $\sqrt{x(x^2 - 2x + 1)} = \sqrt{x(x-1)^2} = |x-1|\sqrt{x}$.

$$I = \int_{0}^{1} (1 - x)\sqrt{x}dx + \int_{1}^{3} (x - 1)\sqrt{x}dx = \int_{0}^{1} \left(x^{\frac{1}{2}} - x^{\frac{3}{2}}\right)dx + \int_{1}^{3} \left(x^{\frac{3}{2}} - x^{\frac{1}{2}}\right)dx$$ $$= \left[\frac{2}{3}x^{\frac{3}{2}} - \frac{2}{5}x^{\frac{5}{2}}\right]_0^1 + \left[\frac{2}{5}x^{\frac{5}{2}} - \frac{2}{3}x^{\frac{3}{2}}\right]_1^3 = \frac{4}{15} + \left(\frac{8\sqrt{3}}{5} + \frac{4}{15}\right) = \frac{24\sqrt{3} + 8}{15}$$

DẠNG 2: TÍCH PHÂN HÀM SỐ CHO BỞI NHIỀU CÔNG THỨC

Cho hàm số $f(x) = \begin{cases} g(x) & \text{khi } x \le b \\ h(x) & \text{khi } x > b \end{cases}$ liên tục trên miền $D$. Để tính $J = \int_{a}^{c} f(x)dx$ với $b \in [a; c]$:

• Bước 1: Kiểm tra tính liên tục tại điểm phân chia $x = b$: $$\lim_{x \to b^-} f(x) = \lim_{x \to b^+} f(x) = f(b) \iff \lim_{x \to b^-} g(x) = \lim_{x \to b^+} h(x) = g(b)$$

• Bước 2: Sử dụng tính chất chèn cận để tách tích phân: $$J = \int_{a}^{c} f(x)dx = \int_{a}^{b} g(x)dx + \int_{b}^{c} h(x)dx$$

Mẫu 1

Cho hàm số $f(x) = \begin{cases} x^2 - 1 & \text{khi } x \ge 2 \\ x^2 - 2x + 3 & \text{khi } x < 2 \end{cases}$. Tính tích phân $I = \int_{1}^{3} f(x)dx$.

1. Tại $x = 2$: $\lim_{x \to 2^+} (x^2 - 1) = 3$; $\lim_{x \to 2^-} (x^2 - 2x + 3) = 3 = f(2) \implies f(x)$ liên tục tại $x = 2$.

2. Tách cận tích phân:

$$I = \int_{1}^{2} (x^2 - 2x + 3)dx + \int_{2}^{3} (x^2 - 1)dx = \left[\frac{x^3}{3} - x^2 + 3x\right]_1^2 + \left[\frac{x^3}{3} - x\right]_2^3 = \frac{7}{3} + \frac{16}{3} = \frac{23}{3}$$
Bài 1

Cho $f(x) = \begin{cases} 3x^2 & \text{khi } 0 \le x \le 1 \\ 4 - x & \text{khi } 1 \le x \le 2 \end{cases}$. Tính $\int_{0}^{2} f(x)dx$.

$$\int_{0}^{2} f(x)dx = \int_{0}^{1} 3x^2 dx + \int_{1}^{2} (4 - x)dx$$ $$= \left[x^3\right]_0^1 + \left[4x - \frac{x^2}{2}\right]_1^2 = 1 + \left(6 - \frac{7}{2}\right) = \frac{7}{2}$$
Bài 2

Cho $f(x) = \begin{cases} 0{,}5x & 0 \le x < 2 \\ 1 & 2 \le x < 15 \\ 4 - 0{,}2x & 15 \le x \le 20 \end{cases}$. Tính $\int_{0}^{20} f(x)dx$.

$$\int_{0}^{20} f(x)dx = \int_{0}^{2} 0{,}5x dx + \int_{2}^{15} 1 dx + \int_{15}^{20} (4 - 0{,}2x)dx$$ $$= 1 + 13 + 2{,}5 = 16{,}5$$
Bài 3

Cho $f(x) = \begin{cases} 2x & \text{khi } x \le 0 \\ a(x - x^2) & \text{khi } x > 0 \end{cases}$ liên tục trên $\mathbb{R}$. Biết $\int_{-1}^{1} f(x)dx = \frac{1}{6}$. Tìm $a$.

Ta có $\int_{-1}^{1} f(x)dx = \int_{-1}^{0} 2x dx + \int_{0}^{1} a(x - x^2)dx = \left[x^2\right]_{-1}^0 + a\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = -1 + \frac{a}{6}$.

Theo giả thiết: $-1 + \frac{a}{6} = \frac{1}{6} \iff \frac{a}{6} = \frac{7}{6} \iff \mathbf{a = 7}$.

Bài 4 (Vận dụng 3 SGK CTST)
Chuyển động của Ca nô cao tốc

Vận tốc: $v(t) = \begin{cases} 0{,}5t, & 0 \le t < 2 \\ 1, & 2 \le t < 15 \\ 4 - 0{,}2t, & 15 \le t \le 20 \end{cases}$ (km/phút). Tính quãng đường trong 20 phút.

Quãng đường đi được chính là tích phân vận tốc theo thời gian:

$$s = \int_{0}^{20} v(t)dt = \int_{0}^{2} 0{,}5t dt + \int_{2}^{15} 1 dt + \int_{15}^{20} (4 - 0{,}2t)dt$$

$$s = \left[0{,}25t^2\right]_0^2 + (15 - 2) + \left[4t - 0{,}1t^2\right]_{15}^{20} = 1 + 13 + 2{,}5 = \mathbf{16{,}5\text{ km}}$$

Bài 5 (Bài 6 SGK CTST)
Chuyển động của Thang máy

Vận tốc: $v(t) = \begin{cases} t, & 0 \le t \le 2 \\ 2, & 2 < t \le 20 \\ 12 - 0{,}5t, & 20 < t \le 24 \end{cases}$ (m/s). Tính quãng đường & $v_{tb}$.

$$s = \int_{0}^{2} t dt + \int_{2}^{20} 2 dt + \int_{20}^{24} (12 - 0{,}5t)dt = 2 + 36 + 4 = \mathbf{42\text{ m}}$$

Tốc độ trung bình: $$v_{tb} = \frac{s}{\Delta t} = \frac{42}{24} = \mathbf{1{,}75\text{ m/s}}$$

Bài 6

Ứng dụng kinh tế học: Lợi nhuận biên $P'(x) = -0{,}0002x + 7{,}5$ (triệu đồng/sản phẩm)

Công thức biến thiên lợi nhuận: $\Delta P = \int_{a}^{b} P'(x)dx = \left[-0{,}0001x^2 + 7{,}5x\right]_a^b$.

a) Doanh số tăng từ 50 lên 60 đơn vị:

$\Delta P = \left[-0{,}0001(3600) + 7{,}5(60)\right] - \left[-0{,}0001(2500) + 7{,}5(50)\right]$

$= 449{,}64 - 374{,}75 = \mathbf{74{,}89\text{ (triệu đồng)}}$

b) Doanh số tăng từ 100 lên 150 đơn vị:

$\Delta P = \left[-0{,}0001(22500) + 7{,}5(150)\right] - \left[-0{,}0001(10000) + 7{,}5(100)\right]$

$= 1122{,}75 - 749 = \mathbf{373{,}75\text{ (triệu đồng)}}$

Bài 7 (Vận dụng cao)

Tìm vị trí $P$ trên đường cong để diện tích phần tô màu lớn nhất

Đáp số: $x = \frac{\sqrt{6}}{3}$
Minh họa phần diện tích tô màu qua điểm P
1. Xác định hàm số $f(x)$

$f(x) = \int \left(-\frac{3}{2}x^2 + 2\right) dx = -\frac{1}{2}x^3 + 2x + C_0$.
Vì $f(2) = 0 \implies -\frac{1}{2}(8) + 4 + C_0 = 0 \iff C_0 = 0$.
Do đó: $\mathbf{f(x) = -\frac{1}{2}x^3 + 2x}$ với $x \in [0; 2]$.

2. Thiết lập diện tích phần tô màu $S(x)$

Hạ đường thẳng đứng $x = x_P$ chia hình thành hai hình thang vuông $OCPH$ và $HPBA$:

$$S(x) = \frac{OC + PH}{2} \cdot OH + \frac{PH + AB}{2} \cdot HA$$
$$= \frac{1 + f(x)}{2} \cdot x + \frac{f(x) + 3}{2} \cdot (2 - x) = f(x) - x + 3$$
3. Tìm giá trị lớn nhất của $S(x)$

Thay $f(x)$ vào: $S(x) = -\frac{1}{2}x^3 + x + 3$ trên $[0; 2]$.
Đạo hàm: $S'(x) = -\frac{3}{2}x^2 + 1 = 0 \iff x^2 = \frac{2}{3} \implies \mathbf{x = \frac{\sqrt{6}}{3}} \in [0; 2]$.

Bài 8 (Nhóm 1, 2, 3, 4)

Cho $f(x) + \frac{1}{2}f'(x) = e^{-2x}, f(0) = 1$. Tính $\int_{0}^{1} \frac{2026 f(x)}{4x + 2}dx$.

• Nhân 2 vế với $2e^{2x}$: $2e^{2x}f(x) + e^{2x}f'(x) = 2 \iff \left[e^{2x}f(x)\right]' = 2$.

• Nguyên hàm: $e^{2x}f(x) = 2x + C$. Với $f(0)=1 \implies C = 1 \implies f(x) = (2x+1)e^{-2x}$.

$$I = \int_{0}^{1} \frac{2026(2x+1)e^{-2x}}{2(2x+1)}dx = 1013\left[-\frac{1}{2}e^{-2x}\right]_0^1 = \mathbf{\frac{1013(e^2 - 1)}{2e^2}}$$

Bài 9 (Nhóm 1, 2, 3)

Cho $f(x) > 0, f(1) = 1$ và $[2f(x) + xf'(x)]^2 = \frac{f(x)}{x}$. Tính diện tích từ $x = e$ đến $x = e^2$.

• Khai căn & chia $2\sqrt{f(x)}$: $\frac{2f(x) + xf'(x)}{2\sqrt{f(x)}} = \frac{1}{2\sqrt{x}} \iff \left[x\sqrt{f(x)}\right]' = \left[\sqrt{x}\right]'$.

• Suy ra $x\sqrt{f(x)} = \sqrt{x} + C$. Do $f(1)=1 \implies C = 0 \implies f(x) = \frac{1}{x}$.

$$S = \int_{e}^{e^2} \frac{1}{x}dx = [\ln x]_e^{e^2} = 2 - 1 = \mathbf{1}$$

II

PHẦN 2: LỜI GIẢI CHI TIẾT BÀI TẬP VỀ NHÀ

Câu 1

Tính các tích phân hàm chứa dấu trị tuyệt đối

a) $\int_{0}^{2} |x^2 + 2x - 3|dx$

Nghiệm trong đoạn $[0; 2]$ là $x = 1$.

$$= \int_{0}^{1} (3 - 2x - x^2)dx + \int_{1}^{2} (x^2 + 2x - 3)dx = \frac{5}{3} + \frac{7}{3} = \mathbf{4}$$
b) $\int_{0}^{2024} |x^2 - 4|dx$

Nghiệm chia đoạn là $x = 2 \in [0; 2024]$.

$$= \int_{0}^{2} (4 - x^2)dx + \int_{2}^{2024} (x^2 - 4)dx = \mathbf{\frac{2024^3 - 24256}{3}}$$
c) $\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} |\sin x|dx$

Vì $|\sin x|$ là hàm số chẵn:

$$= 2\int_{0}^{\frac{\pi}{2}} \sin x dx = 2[-\cos x]_0^{\frac{\pi}{2}} = 2(0 - (-1)) = \mathbf{2}$$
d) $I = \int_{0}^{1} \sqrt{9x^2 - 6x + 1}dx$

$\sqrt{(3x-1)^2} = |3x-1|$, điểm gãy $x = \frac{1}{3}$.

$$= \int_{0}^{\frac{1}{3}} (1 - 3x)dx + \int_{\frac{1}{3}}^{1} (3x - 1)dx = \frac{1}{6} + \frac{2}{3} = \mathbf{\frac{5}{6}}$$
e) Nhóm 1: $\int_{-1}^{2} (x + |1-x| - |x+2|)dx$

Vì $x \in [-1; 2] \implies x+2 > 0$. Điểm đổi dấu là $x = 1$.

$$= \int_{-1}^{1} (-x - 1)dx + \int_{1}^{2} (x - 3)dx = -2 - \frac{3}{2} = \mathbf{-\frac{7}{2}}$$
f) Nhóm 1: $\int_{1}^{5} \frac{2|x-2|+1}{x}dx$

Điểm phân đoạn là $x = 2 \in [1; 5]$.

$$= \int_{1}^{2} \left(\frac{5}{x}-2\right)dx + \int_{2}^{5} \left(2-\frac{3}{x}\right)dx = \mathbf{8\ln 2 - 3\ln 5 + 4}$$
Câu 2

Cho tích phân $I = (\sqrt{3}+\sqrt{2})\int_{-3}^{3} |x^2-1|dx = a\sqrt{3}+b\sqrt{2}$ ($a, b \in \mathbb{Q}$). Tính $P = a + b$.

1. Do hàm $|x^2-1|$ là hàm chẵn: $\int_{-3}^{3} |x^2-1|dx = 2\left(\int_{0}^{1}(1-x^2)dx + \int_{1}^{3}(x^2-1)dx\right) = 2\left(\frac{2}{3} + \frac{20}{3}\right) = \mathbf{\frac{44}{3}}$.

2. Khi đó: $I = \frac{44}{3}(\sqrt{3} + \sqrt{2}) \implies a = b = \frac{44}{3} \implies \mathbf{P = a + b = \frac{88}{3}}$.

Ghi chú sư phạm dành cho giáo viên và học sinh: Trong dòng đề in sẵn có ghi dòng chữ $\frac{20}{3} + \frac{4}{3} + \frac{16}{3} = \frac{40}{3}$. Đây là lỗi đánh máy cơ học từ bản nháp của tác giả đề thi khi viết nhầm $\frac{20}{3}$ thành $\frac{16}{3}$. Nếu chấm theo số liệu in nhầm này thì $a = b = \frac{40}{3} \implies P = \frac{80}{3}$.
Câu 3

Cho $f(x) = \begin{cases} x^2 - 2x + 3 & \text{khi } x \ge 2 \\ x + 1 & \text{khi } x < 2 \end{cases}$. Tính $J = \int_{1}^{3} \frac{1}{2}f(x)dx$.

$$J = \frac{1}{2}\left[\int_{1}^{2} (x+1)dx + \int_{2}^{3} (x^2 - 2x + 3)dx\right] = \frac{1}{2}\left[\frac{5}{2} + \frac{13}{3}\right] = \frac{1}{2} \cdot \frac{41}{6} = \mathbf{\frac{41}{12}}$$
Câu 4 (Vận dụng thực tế)

Quãng đường ô tô chuyển động sau đèn đỏ trong 10 phút đầu

Quãng đường: $8160\text{ m}$
Đồ thị vận tốc chuyển động của ô tô

1. Giai đoạn parabol ($0 \le t \le 6$):

Đỉnh $I(5; 1000)$ và qua gốc tọa độ $O(0; 0) \implies v(t) = a(t-5)^2 + 1000$.
Với $v(0) = 0 \iff 25a + 1000 = 0 \iff a = -40$.
$\implies v(t) = -40(t-5)^2 + 1000 = -40t^2 + 400t$. Tại $t = 6\text{ phút}$: $v(6) = 960\text{ m/phút}$.

2. Giai đoạn thẳng đều ($6 < t \le 10$): Vận tốc không đổi $v(t) = 960\text{ m/phút}$.

3. Tổng quãng đường:

$$S = \int_{0}^{6} (-40t^2 + 400t)dt + 960 \cdot (10 - 6) = \left[-\frac{40}{3}t^3 + 200t^2\right]_0^6 + 3840 = 4320 + 3840 = \mathbf{8160\text{ m}}$$

Xác định hàm đa thức $f(x)$ trùng phương: $f(x) = ax^4 + bx^2 + c$.

• Cực đại $(0; 3) \implies c = 3$.
• Cực tiểu tại $x = \pm 1 \implies 4a(1)^3 + 2b(1) = 0 \iff b = -2a$.
• Giá trị cực tiểu bằng $-2 \implies f(1) = a + b + c = a - 2a + 3 = -2 \iff a = 5 \implies b = -10$.
Vậy: $\mathbf{f(x) = 5x^4 - 10x^2 + 3}$.

a) Nhóm 3, 4, 5, 6

Tính $I_1 = \int_{0}^{2} x^4 \cdot f(x) \, dx$
