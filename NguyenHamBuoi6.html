Câu 1 Nhận biết

Tìm $\int \frac{1}{x^2} dx$.

A. $\int \frac{1}{x^2}dx = \frac{1}{x} + C$
B. $\int \frac{1}{x^2}dx = -\frac{1}{x} + C$ (Đúng)
C. $\int \frac{1}{x^2}dx = \frac{1}{2x} + C$
D. $\int \frac{1}{x^2}dx = \ln x^2 + C$
Chi tiết lời giải SGK

Áp dụng công thức nguyên hàm hàm số luỹ thừa $\int x^\alpha dx = \frac{x^{\alpha+1}}{\alpha+1} + C$ ($\alpha = -2 \ne -1$):

$$\int \frac{1}{x^2} dx = \int x^{-2} dx = \frac{x^{-2+1}}{-2+1} + C = -\frac{1}{x} + C$$

$\rightarrow$ Chọn đáp án B.

Câu 2 Nhận biết

Họ các nguyên hàm của hàm số $f(x) = x^2 - 3x + \frac{1}{x}$ là:

A. $F(x) = 2x - 3 - \frac{1}{x^2} + C$
B. $F(x) = \frac{x^3}{3} - \frac{3}{2}x^2 + \ln|x| + C$ (Đúng)
C. $F(x) = \frac{x^3}{3} + \frac{3}{2}x^2 + \ln x + C$
D. $F(x) = \frac{x^3}{3} - \frac{3}{2}x^2 + \ln x + C$
Chi tiết lời giải SGK

Áp dụng tính chất tuyến tính của nguyên hàm từng thành phần:

$$F(x) = \int \left(x^2 - 3x + \frac{1}{x}\right) dx = \frac{x^3}{3} - \frac{3}{2}x^2 + \ln|x| + C$$

Lưu ý thi trắc nghiệm: Nguyên hàm của $\frac{1}{x}$ bắt buộc phải có giá trị tuyệt đối $\ln|x|$ vì $x$ có thể âm hoặc dương ($x \ne 0$).

$\rightarrow$ Chọn đáp án B.

Câu 3 Nhận biết

Tìm nguyên hàm $\int 7\sin x dx$.

A. $\frac{1}{7}\cos x + C$
B. $-\cos x + C$
C. $-7\cos x + C$
D. $7\sin x + C$
Chi tiết lời giải SGK

Ta có $\int \sin x dx = -\cos x + C$, do đó: $\int 7\sin x dx = -7\cos x + C$.

$\rightarrow$ Chọn đáp án C.

Chi tiết lời giải SGK

Áp dụng công thức nguyên hàm luỹ thừa: $\int x^4 dx = \frac{x^5}{5} + C = \frac{1}{5}x^5 + C$.

$\rightarrow$ Chọn đáp án A.

Câu 5 Thông hiểu

Nguyên hàm của hàm số $f(x) = 3\cos x - 3^x$ là:

A. $\int f(x)dx = 3\sin x - \frac{3^x}{\ln 3} + C$
B. $\int f(x)dx = -3\sin x + \frac{3^x}{\ln 3} + C$
C. $\int f(x)dx = 3\sin x + \frac{3^x}{\ln 3} + C$
D. $\int f(x)dx = -3\sin x - \frac{3^x}{\ln 3} + C$
Chi tiết lời giải SGK

Ta có $\int \cos x dx = \sin x + C$ và $\int a^x dx = \frac{a^x}{\ln a} + C$.

$$\int (3\cos x - 3^x) dx = 3\sin x - \frac{3^x}{\ln 3} + C$$

$\rightarrow$ Chọn đáp án A.

Câu 6 Thông hiểu

Khẳng định nào sau đây sai?

A. $\int [f(x)+g(x)]dx = \int f(x)dx + \int g(x)dx$
B. $\int [f(x)-g(x)]dx = \int f(x)dx - \int g(x)dx$
C. $\int kf(x)dx = k\int f(x)dx, \forall k \in \mathbb{R}$ (Sai)
D. $\int kf(x)dx = k\int f(x)dx, \forall k \in \mathbb{R}, k \ne 0$
Chi tiết phân tích sư phạm SGK

Căn cứ SGK Toán 12: Định lý tính chất của nguyên hàm quy định rõ: $\int k f(x) dx = k \int f(x) dx$ với mọi hằng số $k \ne 0$.

Khi $k = 0$, vế trái là $\int 0 dx = C$ (một họ hàm hằng), trong khi vế phải là $0 \cdot \int f(x)dx = 0$ (một số cố định). Do đó mệnh đề C thiếu điều kiện $k \ne 0$ nên sai.

$\rightarrow$ Chọn đáp án C.

Câu 7 Thông hiểu

Cho hàm số $f(x) = 2x + e^x$. Tìm một nguyên hàm $F(x)$ của hàm số $f(x)$ thoả mãn $F(0) = 2024$.

A. $F(x) = x^2 + e^x + 2023$
B. $F(x) = x^2 + e^x - 2023$
C. $F(x) = x^2 + e^x + 2022$
D. $F(x) = x^2 + e^x - 2024$
Chi tiết lời giải SGK

Họ nguyên hàm: $F(x) = \int (2x + e^x)dx = x^2 + e^x + C$.

Thay điều kiện ban đầu: $F(0) = 0^2 + e^0 + C = 1 + C = 2024 \implies C = 2023$.

Vậy $F(x) = x^2 + e^x + 2023$.

$\rightarrow$ Chọn đáp án A.

Câu 8 Vận dụng vật lý

Một vật chuyển động có gia tốc $a(t) = 3t^2 + t\ (\text{m/s}^2)$. Biết rằng vận tốc ban đầu của vật là $2\ \text{m/s}$. Vận tốc của vật đó sau $2$ giây là:

A. $8\ \text{m/s}$
B. $12\ \text{m/s}$
C. $10\ \text{m/s}$
D. $16\ \text{m/s}$
Chi tiết lời giải SGK

Vận tốc $v(t)$ là một nguyên hàm của gia tốc $a(t)$:

$$v(t) = \int (3t^2 + t)dt = t^3 + \frac{t^2}{2} + C$$

Tại $t = 0$: $v(0) = 2 \implies 0 + C = 2 \implies C = 2 \implies v(t) = t^3 + \frac{t^2}{2} + 2$.

Tại $t = 2$ giây: $v(2) = 2^3 + \frac{2^2}{2} + 2 = 8 + 2 + 2 = 12\ (\text{m/s})$.

$\rightarrow$ Chọn đáp án B.

Câu 9 Thông hiểu

Một nguyên hàm của hàm số $e^{-x} + x$ là:

A. $e^{-x} + 2x + 2025$
B. $-e^{-x} + 2x$
C. $e^{-x} + \frac{x^2}{2} + 2025$
D. $-e^{-x} + \frac{x^2}{2} + 2025$
Chi tiết lời giải SGK

Ta có $\int (e^{-x} + x)dx = -e^{-x} + \frac{x^2}{2} + C$. Với hằng số $C = 2025$, ta nhận được một nguyên hàm tương ứng.

$\rightarrow$ Chọn đáp án D.

Câu 10 Mô hình sinh học

Một cây cà chua được trồng ban đầu có chiều cao $3\text{ cm}$ với tốc độ tăng trưởng được tính bởi công thức $h'(t) = -12t + 3$ (cm/tuần). Công thức nào sau đây tính độ cao của cây sau $t$ tuần?

A. $h(t) = -6t^2 + 3t + 3$
B. $h(t) = 6t^2 + 3t + 3$
C. $h(t) = 6t^2 + 3t$
D. $h(t) = -6t^2 + 3t + 1$
Chi tiết lời giải SGK

Hàm chiều cao $h(t) = \int (-12t + 3)dt = -6t^2 + 3t + C$.

Ban đầu cây cao $3\text{ cm} \implies h(0) = C = 3$. Vậy $h(t) = -6t^2 + 3t + 3$.

$\rightarrow$ Chọn đáp án A.

Câu 11 Thông hiểu

Tìm họ các nguyên hàm $F(x)$ của hàm số $f(x) = \frac{x+3}{x+1}$.

A. $F(x) = x - \ln|x+1| + C$
B. $F(x) = x + \ln|x+1| + C$
C. $F(x) = x - 3\ln|x+1| + C$
D. $F(x) = x + 2\ln|x+1| + C$
Chi tiết biến đổi phân thức

Tách phần nguyên tử số theo mẫu: $\frac{x+3}{x+1} = \frac{(x+1) + 2}{x+1} = 1 + \frac{2}{x+1}$.

$$F(x) = \int \left(1 + \frac{2}{x+1}\right) dx = x + 2\ln|x+1| + C$$

$\rightarrow$ Chọn đáp án D.

Câu 12 Thông hiểu

Họ tất cả các nguyên hàm của hàm số $f(x) = 5^{2x-1}$ là:

A. $\frac{1}{2} \cdot 5^{2x-1} \cdot \ln 5 + C$
B. $2 \cdot 5^{2x-1} \cdot \ln 5 + C$
C. $5^{2x-1} \cdot \ln 5 + C$
D. $\frac{1}{2\ln 5} \cdot 5^{2x-1} + C$
Chi tiết lời giải SGK

Áp dụng công thức nguyên hàm hàm số hợp bậc nhất: $\int a^{kx+b} dx = \frac{1}{k} \cdot \frac{a^{kx+b}}{\ln a} + C$ ($k=2, a=5$):

$$\int 5^{2x-1} dx = \frac{1}{2} \cdot \frac{5^{2x-1}}{\ln 5} + C = \frac{1}{2\ln 5} \cdot 5^{2x-1} + C$$

$\rightarrow$ Chọn đáp án D.

Câu 13 Thông hiểu

Tìm nguyên hàm của hàm số $f(x) = \frac{x^4 + 2}{x^2}$.

A. $\int f(x)dx = \frac{x^3}{3} - \frac{1}{x} + C$
B. $\int f(x)dx = \frac{x^3}{3} + \frac{2}{x} + C$
C. $\int f(x)dx = \frac{x^3}{3} + \frac{1}{x} + C$
D. $\int f(x)dx = \frac{x^3}{3} - \frac{2}{x} + C$
Chi tiết biến đổi

Chia mẫu: $\frac{x^4+2}{x^2} = x^2 + 2x^{-2}$.

$$\int (x^2 + 2x^{-2}) dx = \frac{x^3}{3} + 2\frac{x^{-1}}{-1} + C = \frac{x^3}{3} - \frac{2}{x} + C$$

$\rightarrow$ Chọn đáp án D.

Câu 14 Thông hiểu

Tìm nguyên hàm của hàm số $f(x) = \sqrt{2x-1}$.

A. $\int f(x)dx = \frac{2}{3}(2x-1)\sqrt{2x-1} + C$
B. $\int f(x)dx = \frac{1}{3}(2x-1)\sqrt{2x-1} + C$
C. $\int f(x)dx = -\frac{1}{3}\sqrt{2x-1} + C$
D. $\int f(x)dx = \frac{1}{2}\sqrt{2x-1} + C$
Chi tiết biến đổi

Viết dạng luỹ thừa $(2x-1)^{1/2}$:

$$\int (2x-1)^{1/2} dx = \frac{1}{2} \cdot \frac{(2x-1)^{3/2}}{\frac{3}{2}} + C = \frac{1}{3}(2x-1)\sqrt{2x-1} + C$$

$\rightarrow$ Chọn đáp án B.

Câu 15 Vận dụng

Gọi $F(x)$ là một nguyên hàm của hàm số $f(x) = \frac{x(x-3)^2}{x^2}$, biết $F(1) = \frac{5}{2}$. Tính $F(2)$.

A. $2 + 9\ln 2$
B. $-2 + 9\ln 2$
C. $1 + 9\ln 2$
D. $7$
Chi tiết lời giải SGK

Khai triển tử: $f(x) = \frac{x^3 - 6x^2 + 9x}{x^2} = x - 6 + \frac{9}{x}$ (với $x > 0$).

$F(x) = \frac{x^2}{2} - 6x + 9\ln x + C$.

$F(1) = \frac{1}{2} - 6 + C = \frac{5}{2} \implies C = 8$.

Do đó: $F(2) = \frac{2^2}{2} - 6(2) + 9\ln 2 + 8 = -2 + 9\ln 2$.

$\rightarrow$ Chọn đáp án B.

Câu 16 Vận dụng

Hàm số $f(x) = ax + \frac{b}{x-1}\ (a, b \in \mathbb{Z})$ có nguyên hàm trên $(-\infty; 1)$ là $F(x)$ thỏa mãn $F(0) = -2$ và $F(-1) = \ln 2 - 3$. Khi đó giá trị $a+b$ bằng:

A. $-2$
B. $-1$
C. $0$
D. $1$
Chi tiết giải hệ phương trình vô tỉ

Vì $x \in (-\infty; 1) \implies x - 1 < 0 \implies |x - 1| = 1 - x$.

$F(x) = \frac{a}{2}x^2 + b\ln(1-x) + C$.

  • $F(0) = C = -2$.
  • $F(-1) = \frac{a}{2} + b\ln 2 - 2 = \ln 2 - 3 \iff \frac{a}{2} + b\ln 2 = -1 + \ln 2$.

Do $a, b \in \mathbb{Z}$ và $\ln 2$ là số vô tỉ: $\begin{cases} b = 1 \\ \frac{a}{2} = -1 \end{cases} \iff \begin{cases} a = -2 \\ b = 1 \end{cases}$.

Vậy $a + b = -2 + 1 = -1$.

$\rightarrow$ Chọn đáp án B.

Câu 17 Vận dụng cao

Cho $F(x)$ là một nguyên hàm của hàm số $f(x) = \frac{-x^2-2x}{(x+1)^4}$ thoả $F(-2) = -\frac{2}{3}$. Tính $F(1)$.

A. $\frac{2}{3}$
B. $-\frac{7}{6}$
C. $-\frac{7}{24}$
D. $\frac{11}{24}$
Chi tiết biến đổi hằng đẳng thức

Biến đổi tử theo $(x+1)$: $-x^2 - 2x = -(x+1)^2 + 1$.

$$f(x) = \frac{-(x+1)^2 + 1}{(x+1)^4} = -\frac{1}{(x+1)^2} + \frac{1}{(x+1)^4}$$

Lấy nguyên hàm: $F(x) = \frac{1}{x+1} - \frac{1}{3(x+1)^3} + C$.

Thay $x = -2$: $F(-2) = \frac{1}{-1} - \frac{1}{3(-1)} + C = -1 + \frac{1}{3} + C = -\frac{2}{3} + C$.

Giả thiết $F(-2) = -\frac{2}{3} \implies C = 0$.

Tại $x = 1$: $F(1) = \frac{1}{2} - \frac{1}{3(2)^3} = \frac{1}{2} - \frac{1}{24} = \frac{11}{24}$.

$\rightarrow$ Chọn đáp án D.

II. TRẮC NGHIỆM ĐÚNG - SAI

2 Câu Lớn (8 Ý)
Câu 1 (Nhóm 1, 2, 3 bò) Đúng / Sai Cơ Bản

Cho hàm số $f(x) = 4x^3 - 2x$. Biết $F(x)$ là một nguyên hàm của hàm số $f(x)$. Xét tính đúng sai của các khẳng định sau:

a) $F'(x) = 4x^3 - 2x$ ĐÚNG

Giải thích: Theo định nghĩa SGK, nếu $F(x)$ là nguyên hàm của $f(x)$ thì $F'(x) = f(x) = 4x^3 - 2x$.

b) $\int f(x)dx = x^4 - x^2 + C$ ĐÚNG

Giải thích: $\int (4x^3 - 2x)dx = 4 \frac{x^4}{4} - 2 \frac{x^2}{2} + C = x^4 - x^2 + C$.

c) $F(0)=1 \implies F(x) = x^4 - x^2 - 1$ SAI

Giải thích: $F(0) = 0 - 0 + C = 1 \implies C = 1$. Vậy $F(x) = x^4 - x^2 + 1$. Đề bài cho hằng số $-1$ là sai.

d) Biết $F(0) = 1$. Khi đó $F(-1) = -1$ SAI

Giải thích: $F(-1) = (-1)^4 - (-1)^2 + 1 = 1 - 1 + 1 = 1 \ne -1$.

Câu 2 (Nhóm 1 bò) Vận Dụng Phân Khoảng

Hàm số $f(x)$ xác định trên $\mathbb{R}\setminus\{0\}$ thỏa mãn $f(x) = \frac{x^2+2x-5}{x}$. Xét tính đúng sai của các khẳng định sau:

a) $f(x) = x + 2 - \frac{5}{x}$ ĐÚNG

Giải thích: Tách $\frac{x^2+2x-5}{x} = x + 2 - \frac{5}{x}$ hoàn toàn chính xác.

b) $\int f(x)dx = \frac{x^2}{2} + 2x - 5\ln|x| + C$ ĐÚNG

Giải thích: Lấy nguyên hàm từng thành phần, có trị tuyệt đối chuẩn mực theo SGK.

c) $F(1) = \frac{11}{2} \implies F(x) = \frac{x^2}{2} + 2x - 5\ln|x| - 3$ SAI

Giải thích: $F(1) = \frac{1}{2} + 2 - 0 + C = \frac{5}{2} + C = \frac{11}{2} \implies C = 3$ (khẳng định ghi $-3$).

d) $G(1)=4, G(3)+G(-9)=20 \implies a+b+c = -\frac{7}{2}$ ĐÚNG

Cơ sở lý thuyết bản chất SGK mới: Vì tập xác định gồm 2 khoảng rời $(-\infty; 0)$ và $(0; +\infty)$ nên họ nguyên hàm chứa 2 hằng số độc lập:

$$G(x) = \begin{cases} \frac{x^2}{2} + 2x - 5\ln x + C_1 & (x > 0) \\ \frac{x^2}{2} + 2x - 5\ln(-x) + C_2 & (x < 0) \end{cases}$$

1. Tại $x = 1 > 0$: $G(1) = \frac{5}{2} + C_1 = 4 \implies C_1 = \frac{3}{2}$.

2. Với $x = 3 > 0$: $G(3) = \frac{9}{2} + 6 - 5\ln 3 + \frac{3}{2} = 12 - 5\ln 3$.

3. Vì $G(3) + G(-9) = 20 \implies G(-9) = 20 - (12 - 5\ln 3) = 8 + 5\ln 3$.

Mặt khác: $G(-9) = \frac{81}{2} - 18 - 5\ln 9 + C_2 = \frac{45}{2} - 10\ln 3 + C_2 \implies C_2 = -\frac{29}{2} + 15\ln 3$.

4. Tính $G(-6)$ ($x < 0$):

$$G(-6) = \frac{36}{2} - 12 - 5\ln 6 + C_2 = -\frac{17}{2} - 5\ln 2 + 10\ln 3$$

Suy ra: $a = -5, b = 10, c = -\frac{17}{2} \implies a+b+c = -5 + 10 - \frac{17}{2} = -\frac{7}{2}$.

Câu 1 Vận dụng

Cho $f'(x) = \frac{1}{3x-2}$ trên $\mathbb{R} \setminus \left\{\frac{2}{3}\right\}$, $f(1)=3$ và $f(0)=5$. Giá trị $f(2) + f\left(\frac{1}{3}\right) = \frac{1}{a}\ln b + 8$; $a, b \in \mathbb{Z}$. Tính $a+b$.

Các bước giải:

  • Khoảng $\left(\frac{2}{3}; +\infty\right)$: $f(x) = \frac{1}{3}\ln(3x-2) + C_1$. Vì $f(1) = 3 \implies C_1 = 3$.
    $\implies f(2) = \frac{1}{3}\ln 4 + 3$.
  • Khoảng $\left(-\infty; \frac{2}{3}\right)$: $f(x) = \frac{1}{3}\ln(2-3x) + C_2$. Vì $f(0) = 5 \implies \frac{1}{3}\ln 2 + C_2 = 5 \implies C_2 = 5 - \frac{1}{3}\ln 2$.
    $\implies f\left(\frac{1}{3}\right) = 0 + C_2 = 5 - \frac{1}{3}\ln 2$.
$$f(2) + f\left(\frac{1}{3}\right) = \frac{1}{3}\ln 4 + 3 + 5 - \frac{1}{3}\ln 2 = \frac{1}{3}\ln 2 + 8$$

Đối chiếu: $a = 3, b = 2 \implies a + b = 5$.

Đáp số: 5
Câu 2 Thông hiểu

Biết $\int (\sin x - \cos x)^2 dx = x + \frac{1}{a}\cos bx + C$. Tính tổng $S = a+b$.

Các bước giải:

$$(\sin x - \cos x)^2 = \sin^2 x + \cos^2 x - 2\sin x \cos x = 1 - \sin 2x$$
$$\int (1 - \sin 2x) dx = x + \frac{1}{2}\cos 2x + C$$

Đồng nhất hệ số: $a = 2, b = 2 \implies S = a + b = 4$.

Đáp số: 4
Câu 3 (Sở GD&ĐT Thanh Hóa 2025) Mô hình kinh tế

Sản xuất chiếu cói Nga Sơn: $x$ chiếc ($0 \le x \le 20$). Chi phí biên $C'(x) = 3x^2 - 4x + 10$ (nghìn đồng). Chi phí cố định ban đầu $500$ nghìn đồng. Giá bán $720$ nghìn đồng/chiếc. Tìm lợi nhuận tối đa (nghìn đồng).

Các bước giải:

1. Tổng chi phí: $C(x) = \int (3x^2 - 4x + 10)dx = x^3 - 2x^2 + 10x + 500$ (do $C(0) = 500$).

2. Doanh thu: $R(x) = 720x$.

3. Hàm lợi nhuận: $L(x) = R(x) - C(x) = -x^3 + 2x^2 + 710x - 500$.

Đạo hàm tìm cực trị: $L'(x) = -3x^2 + 4x + 710 = 0 \iff x \approx 16.065$.

Với sản lượng nguyên $x = 16$:

Câu 4: Tìm hàm số $f(x)$

Ta có: $f(x) = \int (8x^3 + \sin x)\,dx = 2x^4 - \cos x + C$.

Với $f(0) = 3 \Rightarrow 2(0)^4 - \cos 0 + C = 3 \Rightarrow -1 + C = 3 \Rightarrow C = 4$.

$$\Rightarrow f(x) = 2x^4 - \cos x + 4$$
