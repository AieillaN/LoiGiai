Trọng Tâm Phương Pháp Cần Nhớ

Nguyên hàm phân thức 2 trường hợp: Với $\int \frac{1}{ax+b}\,dx = \frac{1}{a}\ln|ax+b|+C$, khi biểu thức xét trên $\mathbb{R} \setminus \{x_0\}$, tồn tại 2 hằng số độc lập $C_1, C_2$ trên hai khoảng $(-\infty; x_0)$ và $(x_0; +\infty)$.
$\displaystyle \int f(ax+b)\,dx = \frac{1}{a}F(ax+b)+C$
$\displaystyle f'g + fg' = [f\cdot g]'$
$\displaystyle \frac{f'g - fg'}{g^2} = \left[\frac{f}{g}\right]'$
$\displaystyle \frac{f'}{f^2} = -\left[\frac{1}{f}\right]'$
$\displaystyle \frac{f'}{f} = [\ln|f|]'$
$\displaystyle \frac{f'}{\sqrt{f}} = [2\sqrt{f}]'$
★ PHẦN 1: NGUYÊN HÀM PHÂN THỨC 2 TRƯỜNG HỢP Trang 1
Mẫu 1 (Chuyên Hùng Vương – Gia Lai 2022)
Vận Dụng
Cho hàm số $y=f(x)$ xác định trên $\mathbb{R}\setminus\{2\}$ thỏa mãn $f'(x) = \dfrac{1}{x-2}$, $f(1)=2021$ và $f(3)=2022$. Tính giá trị của biểu thức $P = \dfrac{f(2023)}{f(-2019)}$.
Lời giải chi tiết:
Bước 1: Tìm họ nguyên hàm trên từng khoảng xác định.
Hàm số $f'(x) = \dfrac{1}{x-2}$ liên tục trên hai khoảng riêng biệt $(-\infty; 2)$ và $(2; +\infty)$. Do đó: \[ f(x) = \int \frac{1}{x-2}\,dx = \begin{cases} \ln(x-2) + C_1 & \text{khi } x > 2 \\ \ln(2-x) + C_2 & \text{khi } x < 2 \end{cases} \]
Bước 2: Tìm các hằng số $C_1, C_2$ từ giả thiết ban đầu.
  • Tại $x = 1 < 2$: $f(1) = \ln(2-1) + C_2 = 2021 \implies C_2 = 2021$.
  • Tại $x = 3 > 2$: $f(3) = \ln(3-2) + C_1 = 2022 \implies C_1 = 2022$.
Bước 3: Tính các giá trị $f(2023)$ và $f(-2019)$.
  • Do $2023 > 2$: $f(2023) = \ln(2023 - 2) + C_1 = \ln 2021 + 2022$.
  • Do $-2019 < 2$: $f(-2019) = \ln(2 - (-2019)) + C_2 = \ln 2021 + 2021$.
Kết luận: $P = \dfrac{f(2023)}{f(-2019)} = \dfrac{\ln 2021 + 2022}{\ln 2021 + 2021}$.
Mẫu 2: Nguyên hàm hàm số cho bởi nhiều công thức
Vận Dụng
Cho hàm số $f(x) = \begin{cases} x^2 & \text{khi } x \ge 1 \\ 6x - 5 & \text{khi } x < 1 \end{cases}$. Giả sử $F(x)$ xác định và liên tục trên $\mathbb{R}$ là một nguyên hàm của $f(x)$ thỏa mãn $F(0) = 3$. Tính giá trị của $F(-1) + F(4)$.
Lời giải chi tiết:
Bước 1: Tìm họ nguyên hàm của từng nhánh. \[ F(x) = \begin{cases} \dfrac{x^3}{3} + C_1 & \text{khi } x \ge 1 \\[6pt] 3x^2 - 5x + C_2 & \text{khi } x < 1 \end{cases} \]
Bước 2: Sử dụng điều kiện $F(0)=3$ và tính liên tục tại điểm ranh giới $x=1$.
  • Vì $0 < 1 \implies F(0) = 3(0)^2 - 5(0) + C_2 = 3 \implies C_2 = 3$.
  • Vì $F(x)$ là nguyên hàm trên $\mathbb{R}$ nên $F(x)$ liên tục tại $x = 1$: \[ \lim_{x \to 1^+} F(x) = \lim_{x \to 1^-} F(x) = F(1) \iff \frac{1^3}{3} + C_1 = 3(1)^2 - 5(1) + 3 \iff \frac{1}{3} + C_1 = 1 \implies C_1 = \frac{2}{3}. \]
Bước 3: Tính các giá trị $F(-1)$ và $F(4)$.
  • $F(-1) = 3(-1)^2 - 5(-1) + 3 = 3 + 5 + 3 = 11$.
  • $F(4) = \dfrac{4^3}{3} + \dfrac{2}{3} = \dfrac{64 + 2}{3} = 22$.
Kết luận: $F(-1) + F(4) = 11 + 22 = 33$.
Câu 1 (Bài tập Trang 1)
Vận Dụng
Cho hàm số $f(x)$ xác định trên $\mathbb{R} \setminus \left\{\dfrac{1}{2}\right\}$ thỏa mãn $f'(x) = \dfrac{2}{2x-1}$, $f(0)=1$ và $f(1)=2$. Giá trị của biểu thức $f(-1) + f(3)$ bằng $a + \ln b$ (với $2 \le a, b \in \mathbb{N} \le 20$). Tính tổng $a+b$.
Lời giải chi tiết:
1. Xác định nguyên hàm: \[ f(x) = \int \frac{2}{2x-1}\,dx = \ln|2x-1| + C = \begin{cases} \ln(2x-1) + C_1 & \text{khi } x > \dfrac{1}{2} \\[6pt] \ln(1-2x) + C_2 & \text{khi } x < \dfrac{1}{2} \end{cases} \]
2. Tính hằng số tích phân:
  • $f(0) = 1 \implies \ln(1 - 0) + C_2 = 1 \implies C_2 = 1$.
  • $f(1) = 2 \implies \ln(2 - 1) + C_1 = 2 \implies C_1 = 2$.
3. Tính giá trị yêu cầu: \[ f(-1) = \ln(1 - 2(-1)) + C_2 = \ln 3 + 1 \] \[ f(3) = \ln(2 \cdot 3 - 1) + C_1 = \ln 5 + 2 \] \[ \implies f(-1) + f(3) = 1 + \ln 3 + 2 + \ln 5 = 3 + \ln 15. \] Đối chiếu với dạng $a + \ln b$, ta được $a = 3$, $b = 15$ thỏa mãn $2 \le a, b \le 20$.
Kết luận: $a + b = 3 + 15 = 18$.
Câu 2 (Bài tập Trang 1)
Vận Dụng
Cho hàm số $f(x)$ xác định trên $\mathbb{R} \setminus \{1\}$ thỏa mãn $f'(x) = \dfrac{1}{x-1}$. Biết $f(0) = 2017$, $f(2) = 2018$. Tính $S = \big(f(3) - 2018\big)\big(f(-1) - 2017\big)$.
Lời giải chi tiết:
1. Họ nguyên hàm: \[ f(x) = \begin{cases} \ln(x-1) + C_1 & \text{khi } x > 1 \\ \ln(1-x) + C_2 & \text{khi } x < 1 \end{cases} \]
2. Xác định $C_1, C_2$:
  • $f(0) = \ln 1 + C_2 = 2017 \implies C_2 = 2017$.
  • $f(2) = \ln 1 + C_1 = 2018 \implies C_1 = 2018$.
3. Tính $S$:
  • $f(3) = \ln(3-1) + 2018 = \ln 2 + 2018 \implies f(3) - 2018 = \ln 2$.
  • $f(-1) = \ln(1 - (-1)) + 2017 = \ln 2 + 2017 \implies f(-1) - 2017 = \ln 2$.
Kết luận: $S = (\ln 2) \cdot (\ln 2) = \ln^2 2$.
Câu 3 (Bài tập Trang 1)
Vận Dụng
Cho hàm số $f(x)$ biết $f'(x) = \dfrac{x+1}{x^2}$, thỏa mãn $f(-2) = \dfrac{3}{2}$ và $f(2) = 2\ln 2 - \dfrac{3}{2}$. Giá trị $f(-1)$ bằng bao nhiêu?
Lời giải chi tiết:
1. Phân tích và lấy nguyên hàm: \[ f'(x) = \frac{x+1}{x^2} = \frac{1}{x} + \frac{1}{x^2} \] \[ \implies f(x) = \int \left(\frac{1}{x} + \frac{1}{x^2}\right) dx = \ln|x| - \frac{1}{x} + C = \begin{cases} \ln x - \dfrac{1}{x} + C_1 & \text{khi } x > 0 \\[6pt] \ln(-x) - \dfrac{1}{x} + C_2 & \text{khi } x < 0 \end{cases} \]
2. Tìm hằng số $C_2$ (thuộc khoảng $x < 0$):
Từ giả thiết $f(-2) = \dfrac{3}{2}$: \[ \ln|-2| - \frac{1}{-2} + C_2 = \frac{3}{2} \iff \ln 2 + \frac{1}{2} + C_2 = \frac{3}{2} \implies C_2 = 1 - \ln 2. \] (Giả thiết $f(2)$ cho ta $C_1 = \ln 2 - 1$, tuy nhiên câu hỏi chỉ cần tính tại điểm $x = -1 < 0$).
3. Tính $f(-1)$: \[ f(-1) = \ln|-1| - \frac{1}{-1} + C_2 = 0 + 1 + (1 - \ln 2) = 2 - \ln 2. \]
Kết luận: $f(-1) = 2 - \ln 2$.
Câu 4 (Nhóm 1, 2, 3 – Trang 1)
VDC
Cho hàm số $f(x)$ có đạo hàm trên mỗi khoảng $\left(-\infty; -\dfrac{1}{2}\right)$ và $\left(-\dfrac{1}{2}; +\infty\right)$, đồng thời thỏa mãn $f'(x) = \dfrac{1}{2x+1}$ và $f(-1) + 2f(0) = 2\ln 674$. Giá trị biểu thức $S = f(-2) + f(1) + f(4)$ bằng $a \ln b$ (với $206 \le b \in \mathbb{N} \le 2026$). Tính tổng $a+b$.
Lời giải chi tiết:
1. Xác định cấu trúc nghiệm của $f(x)$ trên 2 khoảng: \[ f(x) = \int \frac{1}{2x+1}\,dx = \frac{1}{2}\ln|2x+1| + C = \begin{cases} \dfrac{1}{2}\ln(2x+1) + C_1 & \text{khi } x > -\dfrac{1}{2} \\[6pt] \dfrac{1}{2}\ln(-2x-1) + C_2 & \text{khi } x < -\dfrac{1}{2} \end{cases} \]
2. Khai thác giả thiết $f(-1) + 2f(0) = 2\ln 674$:
  • Tại $x = 0 > -\dfrac{1}{2}$: $f(0) = \dfrac{1}{2}\ln(1) + C_1 = C_1$.
  • Tại $x = -1 < -\dfrac{1}{2}$: $f(-1) = \dfrac{1}{2}\ln(1) + C_2 = C_2$.
Suy ra: $C_2 + 2C_1 = 2\ln 674$.
3. Phân tích biểu thức $S = f(-2) + f(1) + f(4)$:
  • $f(-2) = \dfrac{1}{2}\ln|-4+1| + C_2 = \dfrac{1}{2}\ln 3 + C_2$ (vì $-2 < -1/2$).
  • $f(1) = \dfrac{1}{2}\ln(3) + C_1$ (vì $1 > -1/2$).
  • $f(4) = \dfrac{1}{2}\ln(9) + C_1 = \dfrac{1}{2}\ln(3^2) + C_1 = \ln 3 + C_1$ (vì $4 > -1/2$).
Cộng vế theo vế: \[ S = \left(\frac{1}{2}\ln 3 + \frac{1}{2}\ln 3 + \ln 3\right) + (C_2 + 2C_1) = 2\ln 3 + 2\ln 674 = 2\big(\ln 3 + \ln 674\big) = 2\ln(3 \cdot 674) = 2\ln 2022. \] Đối chiếu $S = a\ln b$ với $206 \le b \le 2026 \implies a = 2, b = 2022$.
Kết luận: $a + b = 2 + 2022 = 2024$.
Câu 5 (Nhóm 1, 2 – Trang 1)
Vận Dụng
Cho hàm số $f(x) = \begin{cases} 2x-1 & \text{khi } x \ge 1 \\ 3x^2-2 & \text{khi } x < 1 \end{cases}$. Giả sử $F(x)$ là nguyên hàm của $f(x)$ trên $\mathbb{R}$ thỏa mãn $F(0) = 2$. Tính giá trị của $F(-1) + 2F(2)$.
Lời giải chi tiết:
1. Họ nguyên hàm: \[ F(x) = \begin{cases} x^2 - x + C_1 & \text{khi } x \ge 1 \\ x^3 - 2x + C_2 & \text{khi } x < 1 \end{cases} \]
2. Tính hằng số tích phân:
  • Do $0 < 1$: $F(0) = 0^3 - 2(0) + C_2 = 2 \implies C_2 = 2$.
  • Hàm số $F(x)$ liên tục tại $x = 1$: \[ \lim_{x \to 1^+} F(x) = \lim_{x \to 1^-} F(x) \iff 1^2 - 1 + C_1 = 1^3 - 2(1) + 2 \implies C_1 = 1. \]
3. Tính các giá trị:
  • $F(-1) = (-1)^3 - 2(-1) + 2 = -1 + 2 + 2 = 3$.
  • $F(2) = 2^2 - 2 + 1 = 3$.
Do đó: $F(-1) + 2F(2) = 3 + 2(3) = 9$.
Kết luận: $F(-1) + 2F(2) = 9$.
★ PHẦN 2: NGUYÊN HÀM HÀM HỢP VÀ PHƯƠNG TRÌNH VI PHÂN Trang 1 – 2
Mẫu 1: Dạng phân ly biến số vi phân cơ bản
Vận Dụng
Cho hàm số $f(x)$ thỏa mãn $f(2) = -\dfrac{1}{3}$ và $f'(x) = x\big[f(x)\big]^2$ với mọi $x \in \mathbb{R}$. Giá trị của $f(1)$ bằng bao nhiêu?
Lời giải chi tiết:
1. Chuyển vế tách biến: Với $f(x) \ne 0$, chia cả hai vế cho $[f(x)]^2$: \[ \frac{f'(x)}{[f(x)]^2} = x \iff -\left(\frac{1}{f(x)}\right)' = x \]
2. Lấy nguyên hàm hai vế: \[ -\frac{1}{f(x)} = \frac{x^2}{2} + C_0 \iff \frac{1}{f(x)} = -\frac{x^2}{2} + C. \] Thay $x = 2$: \[ \frac{1}{f(2)} = \frac{1}{-\frac{1}{3}} = -3 = -\frac{2^2}{2} + C = -2 + C \implies C = -1. \] Suy ra: \[ \frac{1}{f(x)} = -\frac{x^2}{2} - 1 = -\frac{x^2+2}{2} \implies f(x) = -\frac{2}{x^2+2}. \]
3. Tính $f(1)$: \[ f(1) = -\frac{2}{1^2+2} = -\frac{2}{3}. \]
Kết luận: $f(1) = -\dfrac{2}{3}$.
Mẫu 2 (Nhóm 1, 2, 3 – Trang 1): Đạo hàm tích hoặc thương
VDC
Cho hàm số $y=f(x)$ liên tục trên $\mathbb{R} \setminus \{0; -2\}$ thỏa mãn điều kiện $f(1) = -3\ln 3$ và: \[ x(x+2)f'(x) + 2f(x) = x^2+3x+2. \] Biết $f(2) = a + b\ln 2$ với $a, b \in \mathbb{Q}$. Tính $a^2+b^2$.
Lời giải chi tiết:
1. Nhận dạng đạo hàm của một tích hoặc thương:
Quan sát hệ số $x(x+2)$ và $2$: Ta thấy $\left(\dfrac{x}{x+2}\right)' = \dfrac{1(x+2) - x}{(x+2)^2} = \dfrac{2}{(x+2)^2}$.
Do đó, ta chia hai vế của phương trình cho $(x+2)^2$: \[ \frac{x}{x+2}f'(x) + \frac{2}{(x+2)^2}f(x) = \frac{x^2+3x+2}{(x+2)^2}. \]
2. Thu gọn và nguyên hàm: Vế trái chính là đạo hàm của $\left[\dfrac{x}{x+2}f(x)\right]'$. Phân tích vế phải: \[ \frac{x^2+3x+2}{(x+2)^2} = \frac{(x+1)(x+2)}{(x+2)^2} = \frac{x+1}{x+2} = 1 - \frac{1}{x+2}. \] Lấy nguyên hàm hai vế: \[ \frac{x}{x+2}f(x) = \int \left(1 - \frac{1}{x+2}\right) dx = x - \ln|x+2| + C. \]
3. Tìm $C$ và suy ra $f(2)$ trên khoảng $(0; +\infty)$: Thay $x = 1$: \[ \frac{1}{3}f(1) = 1 - \ln 3 + C \iff \frac{1}{3}(-3\ln 3) = 1 - \ln 3 + C \iff -\ln 3 = 1 - \ln 3 + C \implies C = -1. \] Hàm số thỏa: $\dfrac{x}{x+2}f(x) = x - 1 - \ln(x+2)$.
Thay $x = 2$: \[ \frac{2}{4}f(2) = 2 - 1 - \ln 4 \iff \frac{1}{2}f(2) = 1 - 2\ln 2 \implies f(2) = 2 - 4\ln 2. \] Đồng nhất với dạng $a + b\ln 2 \implies a = 2, b = -4$.
Kết luận: $a^2 + b^2 = 2^2 + (-4)^2 = 20$.
Câu 1 (Bài tập Trang 2): Lượng giác hóa vi phân
Vận Dụng
Cho hàm số $f(x)$ thỏa mãn $f\left(\dfrac{\pi}{4}\right) = 0$ và $f'(x) \cdot 4\sin^2\dfrac{x}{2}\cos^2\dfrac{x}{2} = 1$. Tính $f\left(\dfrac{\pi}{2}\right)$.
Lời giải chi tiết:
1. Biến đổi lượng giác: Áp dụng công thức nhân đôi $\sin x = 2\sin\dfrac{x}{2}\cos\dfrac{x}{2} \implies \sin^2 x = 4\sin^2\dfrac{x}{2}\cos^2\dfrac{x}{2}$.
Phương trình trở thành: \[ f'(x)\cdot \sin^2 x = 1 \iff f'(x) = \frac{1}{\sin^2 x}. \]
2. Tìm hàm số $f(x)$: \[ f(x) = \int \frac{1}{\sin^2 x}\,dx = -\cot x + C. \] Vì $f\left(\dfrac{\pi}{4}\right) = 0 \implies -\cot\left(\dfrac{\pi}{4}\right) + C = 0 \iff -1 + C = 0 \implies C = 1$.
Suy ra: $f(x) = 1 - \cot x$.
3. Tính $f\left(\dfrac{\pi}{2}\right)$: \[ f\left(\frac{\pi}{2}\right) = 1 - \cot\left(\frac{\pi}{2}\right) = 1 - 0 = 1. \]
Kết luận: $f\left(\dfrac{\pi}{2}\right) = 1$.
Câu 2 (Mã 101 – 2020 Đợt 2)
Vận Dụng
Biết $F(x) = e^x + x^2$ là một nguyên hàm của hàm số $f(x)$ trên $\mathbb{R}$. Tính $\displaystyle\int f(2x)\,dx$.
A. $2e^x + 2x^2 + C$ B. $\dfrac{1}{2}e^{2x} + x^2 + C$ C. $\dfrac{1}{2}e^{2x} + 2x^2 + C$ D. $e^{2x} + 4x^2 + C$
Lời giải chi tiết:
Áp dụng công thức đổi biến cơ bản SGK: Nếu $\int f(x)\,dx = F(x) + C$ thì $\displaystyle\int f(ax+b)\,dx = \frac{1}{a}F(ax+b) + C$.
Ở đây $a = 2, b = 0$, ta có: \[ \int f(2x)\,dx = \frac{1}{2}F(2x) + C = \frac{1}{2}\left(e^{2x} + (2x)^2\right) + C = \frac{1}{2}e^{2x} + 2x^2 + C. \]
Kết luận: Chọn đáp án C.
Câu 3 (Bài tập Trang 2)
Vận Dụng
Cho hàm số $y=f(x)$ thỏa mãn $f'(x) \cdot f(x) = x^4 + x^2$. Biết $f(0) = 2$. Tính $f^2(2)$.
Lời giải chi tiết:
1. Nhận xét vi phân: Nhận thấy $f(x)f'(x) = \left[\dfrac{1}{2}f^2(x)\right]'$. Lấy nguyên hàm hai vế: \[ \int f(x)f'(x)\,dx = \int (x^4 + x^2)\,dx \iff \frac{1}{2}f^2(x) = \frac{x^5}{5} + \frac{x^3}{3} + C_0 \] \[ \iff f^2(x) = \frac{2}{5}x^5 + \frac{2}{3}x^3 + C. \]
2. Tìm $C$ và tính $f^2(2)$: Thay $x = 0$: $f^2(0) = 2^2 = 4 \implies C = 4$.
Tại $x = 2$: \[ f^2(2) = \frac{2}{5}(2^5) + \frac{2}{3}(2^3) + 4 = \frac{64}{5} + \frac{16}{3} + 4 = \frac{192 + 80 + 60}{15} = \frac{332}{15}. \]
Kết luận: $f^2(2) = \dfrac{332}{15}$.
Câu 4 (Bài tập Trang 2)
Vận Dụng
Cho hàm số $f(x)$ có đạo hàm và $f(x) > 0, \forall x \in \mathbb{R}$, thỏa mãn $f'(x) = (2x-1)f(x)$ và $f(0) = 1$. Tính $f(2)$.
Lời giải chi tiết:
1. Biến đổi vi phân: Vì $f(x) > 0$, chia cả hai vế cho $f(x)$: \[ \frac{f'(x)}{f(x)} = 2x - 1 \iff [\ln f(x)]' = 2x - 1. \]
2. Lấy nguyên hàm: \[ \ln f(x) = \int (2x-1)\,dx = x^2 - x + C. \] Thay $x = 0$: $\ln f(0) = \ln 1 = 0 \implies 0^2 - 0 + C = 0 \implies C = 0$.
Do đó: $\ln f(x) = x^2 - x \implies f(x) = e^{x^2 - x}$.
3. Tính $f(2)$: \[ f(2) = e^{2^2 - 2} = e^2. \]
Kết luận: $f(2) = e^2$.
Câu 5 (Bài tập Trang 2)
Vận Dụng
Cho hàm số $f(x)$ thỏa mãn $f(2) = -e$ và $f'(x) = e^{-x}\big[f(x)\big]^2$ với mọi $x \in \mathbb{R}$. Tính $f(1)$.
Lời giải chi tiết:
1. Biến đổi vi phân: \[ \frac{f'(x)}{[f(x)]^2} = e^{-x} \iff -\left(\frac{1}{f(x)}\right)' = e^{-x}. \]
2. Lấy nguyên hàm hai vế: \[ -\frac{1}{f(x)} = -e^{-x} + C_0 \iff \frac{1}{f(x)} = e^{-x} + C. \] Thay $x = 2$: \[ \frac{1}{f(2)} = \frac{1}{-e} = -e^{-1} = e^{-2} + C \implies C = -e^{-1} - e^{-2}. \]
3. Tính $f(1)$: \[ \frac{1}{f(1)} = e^{-1} + C = e^{-1} + \left(-e^{-1} - e^{-2}\right) = -e^{-2} = -\frac{1}{e^2} \implies f(1) = -e^2. \]
Kết luận: $f(1) = -e^2$.
Câu 6 (Bài tập Trang 2): Ứng dụng viết phương trình tiếp tuyến
VDC
Cho hàm số $f(x)$ có đạo hàm liên tục trên $(0; +\infty)$ thỏa mãn $f'(x) + \dfrac{f(x)}{x} = 4x^2+3x$ và $f(1) = 2$. Viết phương trình tiếp tuyến của đồ thị hàm số $y=f(x)$ tại điểm có hoành độ $x=2$.
Lời giải chi tiết:
1. Nhân lượng tích phân đưa về đạo hàm tích:
Nhân hai vế với $x > 0$: \[ x f'(x) + f(x) = 4x^3 + 3x^2 \iff [x f(x)]' = 4x^3 + 3x^2. \]
2. Tìm công thức hàm số $f(x)$: \[ x f(x) = \int (4x^3 + 3x^2)\,dx = x^4 + x^3 + C. \] Thay $x = 1$: $1 \cdot f(1) = 2 = 1^4 + 1^3 + C = 2 + C \implies C = 0$.
Do đó: $x f(x) = x^4 + x^3 \implies f(x) = x^3 + x^2$.
3. Lập phương trình tiếp tuyến tại $x_0 = 2$:
  • Tung độ tiếp điểm: $y_0 = f(2) = 2^3 + 2^2 = 8 + 4 = 12$.
  • Hệ số góc: $f'(x) = 3x^2 + 2x \implies k = f'(2) = 3(2^2) + 2(2) = 12 + 4 = 16$.
Phương trình tiếp tuyến có dạng $y = k(x - x_0) + y_0$: \[ y = 16(x - 2) + 12 \iff y = 16x - 20. \]
Kết luận: Phương trình tiếp tuyến là $y = 16x - 20$.
Câu 7 (Nhóm 1, 2 – Trang 2): Cực trị tích phân hàm hợp
VDC
Cho hàm $y = f(x)$ liên tục và có đạo hàm trên $(-\sqrt{2}; \sqrt{2}) \setminus \{0\}$ thỏa mãn $f(1) = 0$ và: \[ f'(x) + x\left(e^{f(x)} + 2\right) + \frac{x}{e^{f(x)}} = 0. \] Tìm giá trị nhỏ nhất của hàm số $g(x) = e^{f(x)} + 2x^2 + 2026$ trên đoạn $\left[-\dfrac{\sqrt{6}}{2}; \dfrac{\sqrt{6}}{2}\right]$.
Lời giải chi tiết:
1. Quy đồng và nhận diện cấu trúc bình phương vi phân: \[ f'(x) + x\left(\frac{e^{2f(x)} + 2e^{f(x)} + 1}{e^{f(x)}}\right) = 0 \iff f'(x) + x\frac{(e^{f(x)}+1)^2}{e^{f(x)}} = 0 \] \[ \iff \frac{e^{f(x)} f'(x)}{(e^{f(x)}+1)^2} = -x \iff \left(-\frac{1}{e^{f(x)}+1}\right)' = -x. \]
2. Lấy nguyên hàm hai vế: \[ \frac{1}{e^{f(x)}+1} = \frac{x^2}{2} + C. \] Thay $x = 1$: Do $f(1) = 0 \implies \dfrac{1}{e^0 + 1} = \dfrac{1}{2} = \dfrac{1^2}{2} + C \implies C = 0$.
Do đó: \[ \frac{1}{e^{f(x)}+1} = \frac{x^2}{2} \iff e^{f(x)}+1 = \frac{2}{x^2} \iff e^{f(x)} = \frac{2}{x^2} - 1. \]
3. Tìm giá trị nhỏ nhất của $g(x)$ bằng bất đẳng thức AM-GM: Hàm số $g(x)$ trở thành: \[ g(x) = \left(\frac{2}{x^2} - 1\right) + 2x^2 + 2026 = \frac{2}{x^2} + 2x^2 + 2025. \] Áp dụng BĐT AM-GM cho hai số dương $\dfrac{2}{x^2}$ và $2x^2$: \[ \frac{2}{x^2} + 2x^2 \ge 2\sqrt{\frac{2}{x^2} \cdot 2x^2} = 2 \cdot 2 = 4. \] \[ \implies g(x) \ge 4 + 2025 = 2029. \] Dấu đẳng thức xảy ra khi: \[ \frac{2}{x^2} = 2x^2 \iff x^4 = 1 \iff x = \pm 1. \] Nhận thấy $x = \pm 1$ hoàn toàn thuộc miền xác định và nằm trong đoạn $\left[-\dfrac{\sqrt{6}}{2}; \dfrac{\sqrt{6}}{2}\right]$ (vì $\dfrac{\sqrt{6}}{2} \approx 1.225 > 1$).
Kết luận: Giá trị nhỏ nhất của $g(x)$ là $2029$.

Câu 1 (Bài tập về nhà)
Vận Dụng
Biết $F(x)$ là một nguyên hàm của hàm số $f(x)$. Khẳng định nào sau đây đúng?
A. $[F(5x)]' = 5f(x)$ B. $[F(5x)]' = f(5x)$ C. $[F(5x)]' = \dfrac{1}{5}f(x)$ D. $[F(5x)]' = 5f(5x)$
Lời giải chi tiết:
Theo định nghĩa đạo hàm hàm số hợp $[F(u(x))]' = u'(x) \cdot F'(u(x))$:
Đặt $u(x) = 5x \implies u'(x) = 5$. Mặt khác vì $F(u)$ là nguyên hàm của $f(u)$ nên $F'(u) = f(u)$.
Do đó: \[ [F(5x)]' = (5x)' \cdot F'(5x) = 5f(5x). \]
Kết luận: Chọn đáp án D.
Câu 2 (Bài tập về nhà)
Vận Dụng
Cho $F(x)$ là một nguyên hàm của hàm số $f(x) = \dfrac{1}{x-2}$ và $F(0) = 1$, $F(3) = 2$. Tính $K = F(4) - F(1)$.
Lời giải chi tiết:
1. Xác định nguyên hàm trên hai khoảng: \[ F(x) = \begin{cases} \ln(x-2) + C_1 & \text{khi } x > 2 \\ \ln(2-x) + C_2 & \text{khi } x < 2 \end{cases} \]
2. Tính hằng số $C_1, C_2$:
  • $F(0) = 1 \implies \ln(2 - 0) + C_2 = 1 \implies C_2 = 1 - \ln 2$.
  • $F(3) = 2 \implies \ln(3 - 2) + C_1 = 2 \implies C_1 = 2$.
3. Tính $F(4)$ và $F(1)$:
  • $F(4) = \ln(4 - 2) + C_1 = \ln 2 + 2$.
  • $F(1) = \ln(2 - 1) + C_2 = 0 + (1 - \ln 2) = 1 - \ln 2$.
Suy ra: \[ K = F(4) - F(1) = (\ln 2 + 2) - (1 - \ln 2) = 1 + 2\ln 2. \]
Kết luận: $K = 1 + 2\ln 2$.
Câu 3 (Bài tập về nhà)
Vận Dụng
Cho hàm số $y=f(x)$ có đạo hàm liên tục trên đoạn $[-2; 1]$ thỏa mãn $f(0) = 3$ và: \[ \big(f(x)\big)^2 \cdot f'(x) = 3x^2 + 4x + 2. \] Giá trị $f(1)$ bằng bao nhiêu?
Lời giải chi tiết:
1. Lấy nguyên hàm hai vế: \[ \int [f(x)]^2 f'(x)\,dx = \int (3x^2 + 4x + 2)\,dx \iff \frac{[f(x)]^3}{3} = x^3 + 2x^2 + 2x + C \] \[ \iff [f(x)]^3 = 3\left(x^3 + 2x^2 + 2x + C\right). \]
2. Khai thác giả thiết $f(0)=3$: \[ \frac{[f(0)]^3}{3} = \frac{3^3}{3} = 9 = 0^3 + 2(0)^2 + 2(0) + C \implies C = 9. \] Do đó: \[ [f(x)]^3 = 3(x^3 + 2x^2 + 2x + 9). \]
3. Tính $f(1)$: \[ [f(1)]^3 = 3(1^3 + 2(1)^2 + 2(1) + 9) = 3(14) = 42 \implies f(1) = \sqrt[3]{42}. \]
Kết luận: $f(1) = \sqrt[3]{42}$.
Câu 4 (Bài tập về nhà)
VDC
Cho hàm số $f(x)$ nhận giá trị dương và có đạo hàm liên tục trên khoảng $(0; +\infty)$ thỏa mãn $f(2) = \dfrac{1}{15}$ và $f'(x) + (2x+4)f^2(x) = 0$. Tính $f(1) + f(2) + f(3)$.
Lời giải chi tiết:
1. Phân ly biến số: Vì $f(x) > 0$, chia cả hai vế cho $f^2(x)$: \[ -\frac{f'(x)}{f^2(x)} = 2x + 4 \iff \left(\frac{1}{f(x)}\right)' = 2x + 4. \]
2. Lấy nguyên hàm: \[ \frac{1}{f(x)} = \int (2x+4)\,dx = x^2 + 4x + C. \] Thay $x = 2$: \[ \frac{1}{f(2)} = 15 = 2^2 + 4(2) + C = 12 + C \implies C = 3. \] Suy ra: \[ f(x) = \frac{1}{x^2+4x+3} = \frac{1}{(x+1)(x+3)}. \]
3. Tính tổng:
  • $f(1) = \dfrac{1}{(1+1)(1+3)} = \dfrac{1}{8}$.
  • $f(2) = \dfrac{1}{15}$.
  • $f(3) = \dfrac{1}{(3+1)(3+3)} = \dfrac{1}{24}$.
Tổng: \[ f(1) + f(2) + f(3) = \left(\frac{1}{8} + \frac{1}{24}\right) + \frac{1}{15} = \frac{4}{24} + \frac{1}{15} = \frac{1}{6} + \frac{1}{15} = \frac{5 + 2}{30} = \frac{7}{30}. \]
Kết luận: $f(1) + f(2) + f(3) = \dfrac{7}{30}$.
Câu 5 (Bài tập về nhà)
Vận Dụng
Cho hàm số $y=f(x)$ thỏa mãn $f(2) = -\dfrac{4}{19}$ và $f'(x) = x^3 f^2(x), \forall x \in \mathbb{R}$. Giá trị của $f(1)$ bằng bao nhiêu?
Lời giải chi tiết:
1. Chuyển vế đạo hàm: \[ \frac{f'(x)}{f^2(x)} = x^3 \iff -\left(\frac{1}{f(x)}\right)' = x^3 \implies \frac{1}{f(x)} = -\frac{x^4}{4} + C. \]
2. Xác định hằng số $C$: Thay $x = 2$: \[ \frac{1}{f(2)} = -\frac{19}{4} = -\frac{2^4}{4} + C = -4 + C \implies C = -\frac{19}{4} + 4 = -\frac{3}{4}. \] Do đó: \[ \frac{1}{f(x)} = -\frac{x^4}{4} - \frac{3}{4} = -\frac{x^4+3}{4} \implies f(x) = -\frac{4}{x^4+3}. \]
3. Tính $f(1)$: \[ f(1) = -\frac{4}{1^4+3} = -\frac{4}{4} = -1. \]
Kết luận: $f(1) = -1$.
Câu 6 (Nhóm 1, 2 – Bài tập về nhà)
VDC
Cho hàm số $f(x)$ xác định trên $(0; +\infty) \setminus \{e\}$, thỏa mãn $f'(x) = \dfrac{1}{x(\ln x - 1)}$, $f(e^2) = 3$ và $f\left(\dfrac{1}{e^2}\right) = \ln 6$. Tính giá trị của biểu thức $f\left(\dfrac{1}{e}\right) - f(e^3)$.
Lời giải chi tiết:
1. Tìm họ nguyên hàm: Ta có vi phân $d(\ln x - 1) = \dfrac{1}{x}dx$. Do đó: \[ f(x) = \int \frac{1}{\ln x - 1}\,d(\ln x - 1) = \ln|\ln x - 1| + C = \begin{cases} \ln(\ln x - 1) + C_1 & \text{khi } x > e \\ \ln(1 - \ln x) + C_2 & \text{khi } 0 < x < e \end{cases} \]
2. Xác định $C_1, C_2$:
  • Vì $e^2 > e$: $f(e^2) = \ln(\ln e^2 - 1) + C_1 = \ln(2 - 1) + C_1 = C_1 \implies C_1 = 3$.
  • Vì $\dfrac{1}{e^2} < e$, có $\ln(e^{-2}) = -2$: \[ f\left(\frac{1}{e^2}\right) = \ln(1 - (-2)) + C_2 = \ln 3 + C_2 = \ln 6 \implies C_2 = \ln 6 - \ln 3 = \ln 2. \]
3. Tính giá trị $f\left(\dfrac{1}{e}\right)$ và $f(e^3)$:
  • Do $\dfrac{1}{e} < e$, với $\ln\left(e^{-1}\right) = -1$: \[ f\left(\frac{1}{e}\right) = \ln(1 - (-1)) + C_2 = \ln 2 + \ln 2 = 2\ln 2. \]
  • Do $e^3 > e$: \[ f(e^3) = \ln(\ln e^3 - 1) + C_1 = \ln(3 - 1) + 3 = \ln 2 + 3. \]
Kết luận: $f\left(\dfrac{1}{e}\right) - f(e^3) = 2\ln 2 - (\ln 2 + 3) = \ln 2 - 3$.
