BÀI 2 – TÍCH PHÂN (ĐỀ A)

Hướng dẫn giải chi tiết, chuẩn sách giáo khoa. Tối ưu giao diện thẻ đơn giản, dễ đọc trên mọi thiết bị di động.

I

Hình Thang Cong

Quy tắc tính diện tích:

Cho $y = f(x) \ge 0$ liên tục trên $[a; b]$. Diện tích hình thang cong giới hạn bởi đồ thị $f(x)$, trục hoành và hai đường thẳng $x = a, x = b$ là:

$$S = F(b) - F(a)$$

(với $F(x)$ là một nguyên hàm của $f(x)$, thường chọn $C = 0$)

Ví dụ 1 (Trang 1) $y = x^2$

Tính diện tích hình thang cong giới hạn bởi $y = f(x) = x^2$, trục hoành và $x = 0; x = 2$.

• Hàm số $y = x^2$ liên tục và không âm trên đoạn $[0; 2]$.

• Một nguyên hàm của $f(x) = x^2$ là $F(x) = \frac{x^3}{3}$.

$$S = F(2) - F(0) = \frac{2^3}{3} - \frac{0^3}{3} = \frac{8}{3}\text{ (đvdt)}$$
Đáp số: $S = \frac{8}{3}$
Bài 1a (Trang 1) $y = \frac{1}{x}$

Tính diện tích giới hạn bởi $y = \frac{1}{x}$, trục hoành và hai đường thẳng $x = 1; x = 3$.

• Với mọi $x \in [1; 3]$ thì $y = \frac{1}{x} > 0$ và liên tục.

• Một nguyên hàm của $\frac{1}{x}$ là $F(x) = \ln x$ (vì $x > 0$).

$$S = F(3) - F(1) = \ln 3 - \ln 1 = \ln 3\text{ (đvdt)}$$
Đáp số: $S = \ln 3$
Bài 1b (Trang 1) $y = 2 - x^2$

Tính diện tích giới hạn bởi $y = 2 - x^2$, trục hoành và hai đường thẳng $x = -1; x = 1$.

• Trên đoạn $[-1; 1]$, ta có $2 - x^2 \ge 1 > 0$.

• Một nguyên hàm của $f(x)$ là $F(x) = 2x - \frac{x^3}{3}$.

$$S = F(1) - F(-1) = \left(2 - \frac{1}{3}\right) - \left(-2 + \frac{1}{3}\right) = \frac{5}{3} - \left(-\frac{5}{3}\right) = \frac{10}{3}$$
Đáp số: $S = \frac{10}{3}$
Bài 1c (Trang 2) $y = e^x$

Tính diện tích giới hạn bởi $y = e^x$, trục hoành, trục tung ($x = 0$) và đường thẳng $x = 1$.

• Hàm số $y = e^x > 0$ liên tục trên $[0; 1]$.

• Một nguyên hàm là $F(x) = e^x$.

$$S = F(1) - F(0) = e^1 - e^0 = e - 1\text{ (đvdt)}$$
Đáp số: $S = e - 1$
II

Định Nghĩa & Tính Chất (Trang 2)

Ví dụ 1 (Đề minh họa 2021)

Tính $\int_1^2 x^3 dx$.

$$\int_1^2 x^3 dx = \left.\frac{x^4}{4}\right\vert_1^2 = \frac{2^4}{4} - \frac{1^4}{4} = \frac{16 - 1}{4} = \mathbf{\frac{15}{4}}$$
Bài 1: Rèn luyện tính tích phân (a → e) Trang 2
a) $\int_1^2 x^2 dx$:
$$\int_1^2 x^2 dx = \left.\frac{x^3}{3}\right\vert_1^2 = \frac{8 - 1}{3} = \mathbf{\frac{7}{3}}$$
b) $\int_1^e \frac{1}{t}dt$:
$$\int_1^e \frac{1}{t}dt = \left.\ln|t|\right\vert_1^e = \ln e - \ln 1 = 1 - 0 = \mathbf{1}$$
c) $\int_{\frac{\pi}{2}}^{-\frac{\pi}{2}} \cos x dx$:
$$\int_{\frac{\pi}{2}}^{-\frac{\pi}{2}} \cos x dx = \left.\sin x\right\vert_{\frac{\pi}{2}}^{-\frac{\pi}{2}} = \sin\left(-\frac{\pi}{2}\right) - \sin\left(\frac{\pi}{2}\right) = -1 - 1 = \mathbf{-2}$$
d) $\int_1^4 \frac{1}{x\sqrt{x}} dx$:

Biến đổi $x\sqrt{x} = x^{\frac{3}{2}} \implies \frac{1}{x\sqrt{x}} = x^{-\frac{3}{2}}$.

$$\int_1^4 x^{-\frac{3}{2}} dx = \left.\left(-2x^{-\frac{1}{2}}\right)\right\vert_1^4 = \left.\left(-\frac{2}{\sqrt{x}}\right)\right\vert_1^4 = -\frac{2}{2} - (-2) = \mathbf{1}$$
e) $\int_0^1 3e \cdot 4^x dx$:
$$3e \int_0^1 4^x dx = 3e\left.\left(\frac{4^x}{\ln 4}\right)\right\vert_0^1 = 3e\left(\frac{4 - 1}{2\ln 2}\right) = \mathbf{\frac{9e}{2\ln 2}}$$
Tính chất tích phân

Ví dụ 1: Cho $\int_0^3 f(x)dx = 5$ và $\int_0^3 g(x)dx = 2$.

• a) $\int_0^3 [f(x) + g(x)]dx = 5 + 2 = \mathbf{7}$.

• b) $\int_0^3 [2f(x) - 3g(x)]dx = 2(5) - 3(2) = 10 - 6 = \mathbf{4}$.

• c) $\int_0^3 [x - 2f(x)]dx = \left.\frac{x^2}{2}\right\vert_0^3 - 2(5) = \frac{9}{2} - 10 = \mathbf{-\frac{11}{2}}$.

Ví dụ 2: Cho $\int_{-2}^2 f(x)dx = 1$, $\int_{-2}^4 f(t)dt = -4$. Tính $\int_2^4 f(y)dy$.

Áp dụng tính chất độc lập biến và nối cận tích phân:

$$\int_2^4 f(y)dy = \int_{-2}^4 f(x)dx - \int_{-2}^2 f(x)dx = -4 - 1 = \mathbf{-5}$$
Rèn luyện tích phân (Trang 3)

Bài 1 (Minh họa 2020):

Cho $\int_1^2 f(x)dx = -2$ và $\int_2^3 f(x)dx = 1$.

$$\int_1^3 f(x)dx = \int_1^2 f(x)dx + \int_2^3 f(x)dx = -2 + 1 = \mathbf{-1}$$

Bài 2: Tính các tích phân

• a) $\int_0^1 (x^6 - 4x^3 + 3x^2)dx = \left.\left(\frac{x^7}{7} - x^4 + x^3\right)\right\vert_0^1 = \mathbf{\frac{1}{7}}$

• b) $\int_1^2 \frac{1}{x^4}dx = \left.\left(-\frac{1}{3x^3}\right)\right\vert_1^2 = -\frac{1}{24} - \left(-\frac{1}{3}\right) = \mathbf{\frac{7}{24}}$

• c) $\int_0^{\frac{\pi}{2}} (4\sin x + 3\cos x)dx = \left.(-4\cos x + 3\sin x)\right\vert_0^{\frac{\pi}{2}} = 3 - (-4) = \mathbf{7}$

• d) $\int_{-1}^2 (3x+1)(x+3)dx = \int_{-1}^2 (3x^2 + 10x + 3)dx = \left.(x^3 + 5x^2 + 3x)\right\vert_{-1}^2 = 34 - 1 = \mathbf{33}$

• e) $\int_1^3 \frac{x+2}{x}dx = \int_1^3 \left(1 + \frac{2}{x}\right)dx = \left.(x + 2\ln|x|)\right\vert_1^3 = \mathbf{2 + 2\ln 3}$

• f) $\int_1^2 e^x\left(1 - \frac{e^{-x}}{x}\right)dx = \int_1^2 \left(e^x - \frac{1}{x}\right)dx = \left.(e^x - \ln|x|)\right\vert_1^2 = \mathbf{e^2 - e - \ln 2}$

Ứng Dụng Chuyển Động & Kinh Tế

Vật lý • Bài 3 Quãng đường hãm phanh

Xe đang chạy $20\text{ m/s}$ thì hãm phanh với $v(t) = 20 - 5t\text{ (m/s)}$. Kể từ khi hãm phanh đến khi dừng, xe đi được bao nhiêu mét?

• Bước 1: Khi xe dừng hẳn thì vận tốc bằng $0$:

$$v(t) = 0 \iff 20 - 5t = 0 \iff t = 4\text{ (giây)}$$

• Bước 2: Quãng đường xe đi được là tích phân vận tốc từ $t = 0$ đến $t = 4$:

$$s = \int_0^4 (20 - 5t)dt = \left.\left(20t - \frac{5t^2}{2}\right)\right\vert_0^4 = 80 - 40 = 40\text{ (m)}$$
Đáp số: $40\text{ m}$
Vật lý • Bài 4 $v(t) = 2t - 0{,}03t^2$

Ô tô xuất phát với vận tốc $v(t) = 2t - 0{,}03t^2\text{ (m/s)}$ với $0 \le t \le 10$.

a) Quãng đường xe đi được:

• Sau $5\text{ s}$:

$$s(5) = \int_0^5 (2t - 0{,}03t^2)dt = \left.\left(t^2 - 0{,}01t^3\right)\right\vert_0^5 = 25 - 1{,}25 = \mathbf{23{,}75\text{ m}}$$

• Sau $10\text{ s}$:

$$s(10) = \int_0^{10} (2t - 0{,}03t^2)dt = \left.\left(t^2 - 0{,}01t^3\right)\right\vert_0^{10} = 100 - 10 = \mathbf{90\text{ m}}$$

b) Vận tốc trung bình trong 10 giây đầu:

$$v_{\text{tb}} = \frac{s(10)}{\Delta t} = \frac{90}{10} = \mathbf{9\text{ m/s}}$$
Kinh tế • Bài 5 Chi phí cận biên $C'(x)$

Biết chi phí cận biên $C'(x) = 5 - 0{,}06x + 0{,}00072x^2$ và chi phí cố định $C(0) = 30$ triệu đồng. Tính tổng chi phí khi sản xuất 100 tấn.

• Mối quan hệ tích phân: $C(100) - C(0) = \int_0^{100} C'(x)dx$.

$$\int_0^{100} (5 - 0{,}06x + 0{,}00072x^2)dx = \left.\left(5x - 0{,}03x^2 + 0{,}00024x^3\right)\right\vert_0^{100}$$ $$= 500 - 300 + 240 = 440\text{ (triệu đồng)}$$

• Tổng chi phí sản xuất 100 tấn là:

$$C(100) = C(0) + 440 = 30 + 440 = 470\text{ (triệu đồng)}$$
Đáp số: $470\text{ triệu đồng}$
Kinh tế • Bài 6 Lợi nhuận cận biên $P'(x)$

Lợi nhuận cận biên $P'(x) = 16 - 0{,}02x$. Nếu không bán được thì lỗ 25 triệu ($P(0) = -25$). Tính lợi nhuận khi bán 90 tấn.

• Ta có: $P(90) - P(0) = \int_0^{90} (16 - 0{,}02x)dx$.

$$\int_0^{90} (16 - 0{,}02x)dx = \left.\left(16x - 0{,}01x^2\right)\right\vert_0^{90} = 1440 - 81 = 1359\text{ (triệu)}$$

• Lợi nhuận thu được khi bán 90 tấn:

$$P(90) = P(0) + 1359 = -25 + 1359 = 1334\text{ (triệu đồng)}$$
Đáp số: $1334\text{ triệu đồng}$
Thực tế • Bài 7 Cổng ĐH Bách Khoa Hà Nội

Cổng hình parabol có chiều rộng $8\text{ m}$, chiều cao $12{,}5\text{ m}$. Tính diện tích cổng.

• Chọn hệ trục tọa độ $Oxy$ với đỉnh parabol tại $I(0; 12{,}5)$, cắt đất tại hai điểm $A(-4; 0)$ và $B(4; 0)$.

• Phương trình parabol có dạng: $y = -ax^2 + 12{,}5$.

• Đi qua $B(4; 0) \implies 0 = -a(4^2) + 12{,}5 \implies a = \frac{12{,}5}{16} = \frac{25}{32}$.

$$S = \int_{-4}^4 \left(12{,}5 - \frac{25}{32}x^2\right)dx = 2\left.\left(12{,}5x - \frac{25}{96}x^3\right)\right\vert_0^4 = \mathbf{\frac{200}{3} \approx 66{,}67\text{ m}^2}$$

💡 Công thức tính nhanh Archimedes: $S = \frac{2}{3} \times \text{rộng} \times \text{cao} = \frac{2}{3} \times 8 \times 12{,}5 = \frac{200}{3}\text{ m}^2$.

Đáp số: $\frac{200}{3}\text{ m}^2$

Bài 8 (Trang 4) Cực trị hàm ẩn

Cho $f'(x) = \frac{x^2 - x + 1}{xf(x)}$ trên $(0; +\infty)$ và $f(1) = 1$. Tìm số điểm cực trị của $g(x) = f^2(x) - 2\ln x - \frac{1}{3}x^3 + \frac{1}{2}x^2 + 5x$.

• Bước 1: Nhân chéo tách biến:

$$f(x)f'(x) = \frac{x^2 - x + 1}{x} = x - 1 + \frac{1}{x}$$

• Bước 2: Lấy nguyên hàm hai vế:

$$\int f(x)f'(x)dx = \int \left(x - 1 + \frac{1}{x}\right)dx \implies \frac{1}{2}f^2(x) = \frac{x^2}{2} - x + \ln x + C$$

Do $f(1) = 1 \implies \frac{1}{2} = -\frac{1}{2} + C \implies C = 1$. Suy ra:

$$f^2(x) = x^2 - 2x + 2\ln x + 2$$

• Bước 3: Thay $f^2(x)$ vào biểu thức của $g(x)$:

$$g(x) = (x^2 - 2x + 2\ln x + 2) - 2\ln x - \frac{1}{3}x^3 + \frac{1}{2}x^2 + 5x = -\frac{1}{3}x^3 + \frac{3}{2}x^2 + 3x + 2$$

• Bước 4: Khảo sát cực trị $g'(x) = -x^2 + 3x + 3 = 0$. Vì hệ số $ac = -3 < 0$, phương trình luôn có 2 nghiệm trái dấu $x_1 < 0 < x_2$.

Vì tập xác định $x \in (0; +\infty)$, chỉ có nghiệm dương $x_2 = \frac{3 + \sqrt{21}}{2}$ thỏa mãn và $g'(x)$ đổi dấu qua điểm này.

Đáp số: Có đúng 1 điểm cực trị
Bài 9 & Bài 10 (Trang 4) Đạo hàm cấp hai $f''(x)$

Cho hàm số $y = f(x)$ thỏa $[xf'(x)]^2 + 1 = x^2[1 - f(x)f''(x)]$ với mọi $x > 0$ và $f(1) = f'(1) = 1$.

🔑 Phương pháp biến đổi mấu chốt:

$$x^2[f'(x)]^2 + 1 = x^2 - x^2 f(x)f''(x) \iff x^2\left([f'(x)]^2 + f(x)f''(x)\right) = x^2 - 1$$ $$\iff [f'(x)]^2 + f(x)f''(x) = 1 - \frac{1}{x^2}$$

Nhận xét rằng: $[f(x)f'(x)]' = [f'(x)]^2 + f(x)f''(x)$.

Lấy nguyên hàm hai vế theo $x$:

$$f(x)f'(x) = \int \left(1 - \frac{1}{x^2}\right)dx = x + \frac{1}{x} + C_1$$

Do $f(1) = 1, f'(1) = 1 \implies 1 = 1 + 1 + C_1 \implies C_1 = -1$. Do đó:

$$f(x)f'(x) = x - 1 + \frac{1}{x}$$

Lấy nguyên hàm lần thứ hai: $\frac{1}{2}f^2(x) = \frac{x^2}{2} - x + \ln x + C_2$. Vì $f(1) = 1 \implies C_2 = 1$.

$$\implies f^2(x) = x^2 - 2x + 2\ln x + 2$$

Giải Bài 9: Tính $\int_1^4 [f^2(x) - 2\ln x]dx$

Thay $f^2(x) - 2\ln x = x^2 - 2x + 2$ vào tích phân:

$$\int_1^4 (x^2 - 2x + 2)dx = \left.\left(\frac{x^3}{3} - x^2 + 2x\right)\right\vert_1^4 = \left(\frac{64}{3} - 16 + 8\right) - \left(\frac{1}{3} - 1 + 2\right) = \mathbf{12}$$

Đáp số Bài 9: $12$

Giải Bài 10: Tìm số điểm cực trị của $g(x) = f^2(x) - 2x^2 + 4x$

Ta có: $g(x) = (x^2 - 2x + 2\ln x + 2) - 2x^2 + 4x = -x^2 + 2x + 2\ln x + 2$.

$$g'(x) = -2x + 2 + \frac{2}{x} = \frac{-2x^2 + 2x + 2}{x} = \frac{-2(x^2 - x - 1)}{x}$$

Phương trình $x^2 - x - 1 = 0$ có 1 nghiệm dương duy nhất trên $(0; +\infty)$ là $x = \frac{1 + \sqrt{5}}{2}$. Đạo hàm đổi dấu từ dương sang âm qua nghiệm này.

Đáp số Bài 10: 1 điểm cực trị

Câu 1: Tính các tích phân (a → g)
a) $\int_0^2 (2x + 1)dx$:
$$\left.\left(x^2 + x\right)\right\vert_0^2 = (4 + 2) - 0 = \mathbf{6}$$
b) $\int_1^e \left(\frac{1}{x} - \frac{1}{x^2}\right)dx$:
$$\left.\left(\ln|x| + \frac{1}{x}\right)\right\vert_1^e = \left(1 + \frac{1}{e}\right) - (0 + 1) = \mathbf{\frac{1}{e}}$$
c) $\int_1^3 \frac{x+2}{x}dx$:
$$\int_1^3 \left(1 + \frac{2}{x}\right)dx = \left.(x + 2\ln|x|)\right\vert_1^3 = (3 + 2\ln 3) - (1 + 0) = \mathbf{2 + 2\ln 3}$$
d) $\int_0^1 e^{3x+1}dx$:
$$\left.\left(\frac{1}{3}e^{3x+1}\right)\right\vert_0^1 = \frac{e^4 - e^1}{3} = \mathbf{\frac{e^4 - e}{3}}$$
e) $\int_0^1 \frac{e^x}{2^x}dx = \int_0^1 \left(\frac{e}{2}\right)^x dx$:
$$\left.\left(\frac{(e/2)^x}{\ln(e/2)}\right)\right\vert_0^1 = \frac{\frac{e}{2} - 1}{\ln e - \ln 2} = \mathbf{\frac{e - 2}{2(1 - \ln 2)}}$$
f) $\int_{\frac{\pi}{3}}^{\frac{\pi}{2}} (2\sin x + 3\cos x + x)dx$:
$$\left.\left(-2\cos x + 3\sin x + \frac{x^2}{2}\right)\right\vert_{\frac{\pi}{3}}^{\frac{\pi}{2}} = \left(0 + 3 + \frac{\pi^2}{8}\right) - \left(-1 + \frac{3\sqrt{3}}{2} + \frac{\pi^2}{18}\right) = \mathbf{4 - \frac{3\sqrt{3}}{2} + \frac{5\pi^2}{72}}$$
g) $\int_0^{\frac{\pi}{2}} \sin^2\frac{x}{4}\cos^2\frac{x}{4}dx$:

Sử dụng công thức nhân đôi: $\sin\frac{x}{4}\cos\frac{x}{4} = \frac{1}{2}\sin\frac{x}{2} \implies \sin^2\frac{x}{4}\cos^2\frac{x}{4} = \frac{1}{4}\sin^2\frac{x}{2} = \frac{1 - \cos x}{8}$.

$$\int_0^{\frac{\pi}{2}} \frac{1 - \cos x}{8} dx = \left.\frac{1}{8}(x - \sin x)\right\vert_0^{\frac{\pi}{2}} = \frac{1}{8}\left(\frac{\pi}{2} - 1\right) = \mathbf{\frac{\pi - 2}{16}}$$

Nếu $\int_{-1}^4 f(x)dx = 2$ và $\int_{-1}^4 g(x)dx = 3$ thì $\int_{-1}^4 [f(x) + g(x)]dx$ bằng bao nhiêu?

Câu 3 (Minh họa 2023)

Nếu $\int_0^2 f(x)dx = 4$ thì $\int_0^2 \left[\frac{1}{2}f(x) - 2\right]dx$ bằng bao nhiêu?

$$\int_0^2 \left[\frac{1}{2}f(x) - 2\right]dx = \frac{1}{2}\int_0^2 f(x)dx - \int_0^2 2dx = \frac{1}{2}(4) - 2(2) = 2 - 4 = \mathbf{-2}$$
Câu 4: Tìm số giá trị nguyên $m$

Cho $I = \int_0^1 (4x - 2m^2)dx$. Có bao nhiêu giá trị nguyên của $m$ để $I + 6 > 0$?

• Bước 1: Tính tích phân $I$:

$$I = \left.\left(2x^2 - 2m^2 x\right)\right\vert_0^1 = 2 - 2m^2$$

• Bước 2: Bất phương trình:

$$I + 6 > 0 \iff (2 - 2m^2) + 6 > 0 \iff 8 - 2m^2 > 0 \iff m^2 < 4 \iff -2 < m < 2$$

Do $m \in \mathbb{Z} \implies m \in \{-1; 0; 1\}$ (có 3 giá trị nguyên thỏa mãn).

Đáp số: 3 giá trị

Câu 6 (Nhóm 4, 5, 6) Xác định hàm $f(x)$

Cho $f(x) = x^3 + ax^2 + bx + c$ cắt $Ox$ tại $(-1; 0)$, cắt $Oy$ tại $(0; 4)$ và đạt cực tiểu tại $x = 2$. Tính $\int_2^9 f(x)dx$.

1. Cắt $Oy$ tại $(0; 4) \implies f(0) = c = 4$.

2. Cắt $Ox$ tại $(-1; 0) \implies f(-1) = (-1)^3 + a(-1)^2 + b(-1) + 4 = 0 \iff a - b = -3$.

3. Đạt cực tiểu tại $x = 2 \implies f'(2) = 0$.
Ta có $f'(x) = 3x^2 + 2ax + b \implies f'(2) = 12 + 4a + b = 0 \iff 4a + b = -12$.

4. Giải hệ phương trình:

$$\begin{cases} a - b = -3 \\ 4a + b = -12 \end{cases} \iff \begin{cases} a = -3 \\ b = 0 \end{cases} \implies f(x) = x^3 - 3x^2 + 4$$

5. Tính tích phân:

Câu 7 (Nhóm 1, 2, 3) Khoảng cách cực trị $x_B - x_A = 3$

Cho $f(x) = x^3 + ax^2 + bx + c$ có $A$ (cực đại), $B$ (cực tiểu) với $x_B - x_A = 3$. Đồ thị cắt $Ox$ tại $x = 2$, cắt $Oy$ tại $y = 10$. Tính $\int_2^9 f(x)dx$.

1. Cắt $Oy$ tại $y = 10 \implies c = 10$.

2. Cắt $Ox$ tại $x = 2 \implies 2^3 + 4a + 2b + 10 = 0 \iff 4a + 2b = -18 \iff b = -2a - 9$.

3. Vì hệ số $x^3$ là $1 > 0$, hàm số đạt cực đại tại nghiệm nhỏ hơn ($x_A$) và cực tiểu tại nghiệm lớn hơn ($x_B$).
Phương trình $f'(x) = 3x^2 + 2ax + b = 0$ có 2 nghiệm phân biệt thỏa $(x_B - x_A)^2 = 9$.

Theo định lý Viète: $x_A + x_B = -\frac{2a}{3};\ x_A x_B = \frac{b}{3}$. Do đó:

$$(x_B - x_A)^2 = (x_A + x_B)^2 - 4x_A x_B = \frac{4a^2}{9} - \frac{4b}{3} = 9 \iff 4a^2 - 12b = 81$$

Thế $b = -2a - 9$ vào:

$$4a^2 - 12(-2a - 9) = 81 \iff 4a^2 + 24a + 27 = 0 \iff a = -\frac{3}{2} \text{ hoặc } a = -\frac{9}{2}$$
• Trường hợp 1: $a = -\frac{3}{2} \implies b = -6$

$f'(x) = 3x^2 - 3x - 6 = 0 \iff x_A = -1, x_B = 2$ (thỏa mãn $x_B - x_A = 3$).

Hàm số: $f(x) = x^3 - \frac{3}{2}x^2 - 6x + 10$.

$$\int_2^9 \left(x^3 - \frac{3}{2}x^2 - 6x + 10\right)dx = \left.\left(\frac{x^4}{4} - \frac{x^3}{2} - 3x^2 + 10x\right)\right\vert_2^9 = \mathbf{\frac{4459}{4} = 1114{,}75}$$
• Trường hợp 2: $a = -\frac{9}{2} \implies b = 0$

$f'(x) = 3x^2 - 9x = 0 \iff x_A = 0, x_B = 3$ (thỏa mãn $x_B - x_A = 3$).

Hàm số: $f(x) = x^3 - \frac{9}{2}x^2 + 10$.

$$\int_2^9 \left(x^3 - \frac{9}{2}x^2 + 10\right)dx = \left.\left(\frac{x^4}{4} - \frac{3x^3}{2} + 10x\right)\right\vert_2^9 = \mathbf{\frac{2499}{4} = 624{,}75}$$
Đáp số: $1114{,}75$ hoặc $624{,}75$
