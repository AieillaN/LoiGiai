VI. Góc Giữa Hai Mặt Phẳng

Cho $(P)$ có VTPT $\vec{n}_1 = (a_1; b_1; c_1)$ và $(Q)$ có VTPT $\vec{n}_2 = (a_2; b_2; c_2)$. Góc $\alpha = ((P), (Q))$ ($0^\circ \le \alpha \le 90^\circ$):

$$\cos\alpha = \frac{\vert\vec{n}_1 \cdot \vec{n}_2\vert}{\vert\vec{n}_1\vert \cdot \vert\vec{n}_2\vert} = \frac{\vert a_1 a_2 + b_1 b_2 + c_1 c_2\vert}{\sqrt{a_1^2 + b_1^2 + c_1^2}\cdot\sqrt{a_2^2 + b_2^2 + c_2^2}}$$

Ví dụ 1: Tính góc giữa $(P): 2x - y - 2z - 9 = 0$ và $(Q): x - y - 6 = 0$.

  • VTPT: $\vec{n}_1 = (2; -1; -2) \implies |\vec{n}_1| = 3$; $\vec{n}_2 = (1; -1; 0) \implies |\vec{n}_2| = \sqrt{2}$.
  • $\cos\alpha = \dfrac{|2(1) + (-1)(-1) + 0|}{3\sqrt{2}} = \dfrac{\sqrt{2}}{2} \implies \mathbf{\alpha = 45^\circ}$.

Câu 8: Tọa độ điểm thỏa điều kiện hình học

Cho $A(1;-2;0), B(-3;1;1), C(3;-1;1)$. $M(a, b, c) \in (ABC)$, $\triangle ABM$ cân tại $M$, $MA \parallel (Oyz)$. Tính $a + 18b + 6c$.

• $(ABC)$ có VTPT $[\vec{AB}, \vec{AC}] \parallel (1; 3; -5) \implies x + 3y - 5z + 5 = 0$.

• $MA \parallel (Oyz): x = 0 \implies x_M = x_A \implies \mathbf{a = 1}$.

• $M \in (ABC) \implies 3b - 5c + 6 = 0$ $(1)$.

• $MA^2 = MB^2 \iff 3b + c = 7$ $(2)$.

Từ (1) và (2) $\implies b = \frac{29}{18}, c = \frac{13}{6}$.

$$T = a + 18b + 6c = 1 + 18\left(\frac{29}{18}\right) + 6\left(\frac{13}{6}\right) = \mathbf{43}$$
Câu 9: Cực trị khoảng cách Trọng tâm

Cho $A(1; 1; 2)$ và $(P): (m - 1)x + y + mz - 1 = 0$. Tìm $m$ để $d(A, (P))$ lớn nhất.

Cách 1: Bản chất hình học (Trục quay)

$(P)$ luôn chứa đường thẳng $\Delta: \begin{cases} x + z = 0 \\ -x + y - 1 = 0 \end{cases} \implies \vec{u}_\Delta = (1; 1; -1)$.

Gọi $H(t; 1+t; -t) \in \Delta$ là hình chiếu của $A$ lên $\Delta$. Ta có $d(A, (P)) \le AH$.

Khoảng cách cực đại khi $(P) \perp AH \iff \vec{AH} \cdot \vec{u}_\Delta = 0 \iff t = -\frac{1}{3} \implies \vec{AH} \parallel (4; 1; 5)$.

Khi đó: $\vec{n}_P = (m - 1; 1; m) \parallel (4; 1; 5) \implies \frac{m-1}{4} = \frac{1}{1} = \frac{m}{5} \iff \mathbf{m = 5}$.

Cách 2: Đại số (Hàm số khoảng cách)

Công thức: $d(A, (P)) = \dfrac{|(m-1)(1) + 1 + 2m - 1|}{\sqrt{(m-1)^2 + 1 + m^2}} = \dfrac{|3m - 1|}{\sqrt{2m^2 - 2m + 2}}$.

Xét hàm bình phương: $f(m) = \dfrac{9m^2 - 6m + 1}{2m^2 - 2m + 2} \implies f'(m) = \dfrac{(3m - 1)(5 - m)}{2(m^2 - m + 1)^2}$.

$f'(m) = 0 \iff m = \frac{1}{3}$ (cực tiểu $= 0$) hoặc $\mathbf{m = 5}$ (cực đại $= \frac{14}{3}$).

Kết luận: $d_{\max} = \sqrt{\frac{14}{3}}$ đạt được khi $\mathbf{m = 5}$.

Câu 11b: Trực tâm tam giác trong không gian Trọng tâm Oxyz

Trong không gian $Oxyz$, cho các điểm $A(1; 0; 3)$, $B(-1; 2; 1)$, $C(0; 1; 4)$. Gọi $H(x_0; y_0; z_0)$ là trực tâm của tam giác $ABC$. Tính giá trị biểu thức $P = x_0 - y_0$.

1. Cơ sở lý thuyết sư phạm:

Điểm $H(a; b; c)$ là trực tâm của $\triangle ABC$ khi và chỉ khi $H$ đồng phẳng với ba đỉnh $A, B, C$ và thỏa mãn hai điều kiện vuông góc của đường cao:

$\begin{cases} [\vec{AB}, \vec{AC}] \cdot \vec{AH} = 0 & \text{($H$ thuộc mặt phẳng $(ABC)$)} \\ \vec{CH} \cdot \vec{AB} = 0 & (CH \perp AB) \\ \vec{BH} \cdot \vec{AC} = 0 & (BH \perp AC) \end{cases}$
2. Thiết lập các vectơ chỉ phương & pháp tuyến:
  • $\vec{AB} = (-2; 2; -2) = -2(1; -1; 1)$
  • $\vec{AC} = (-1; 1; 1)$
  • Tích có hướng: $[\vec{AB}, \vec{AC}] = (4; 4; 0) = 4(1; 1; 0) \implies \vec{n}_{(ABC)} = (1; 1; 0)$
  • Các vectơ liên quan đến $H(a; b; c)$:
    $\vec{AH} = (a - 1; b; c - 3)$
    $\vec{CH} = (a; b - 1; c - 4)$
    $\vec{BH} = (a + 1; b - 2; c - 1)$
3. Lập hệ phương trình xác định tọa độ $H$:
  • • Mặt phẳng $(ABC)$ qua $A(1;0;3)$ có dạng: $1(x - 1) + 1(y - 0) + 0(z - 3) = 0 \iff x + y - 1 = 0$.
    Do $H \in (ABC) \implies \mathbf{a + b - 1 = 0} \iff a + b = 1 \quad (1)$
  • • $CH \perp AB \iff \vec{CH} \cdot (1; -1; 1) = 0$:
    $1(a) - 1(b - 1) + 1(c - 4) = 0 \iff \mathbf{a - b + c = 3} \quad (2)$
  • • $BH \perp AC \iff \vec{BH} \cdot \vec{AC} = 0$:
    $-1(a + 1) + 1(b - 2) + 1(c - 1) = 0 \iff \mathbf{-a + b + c = 4} \quad (3)$
4. Giải hệ phương trình và kết luận:

Từ $(2)$ và $(3)$, trừ vế theo vế ta được: $2a - 2b = -1 \iff a - b = -\frac{1}{2}$.

Kết hợp với $(1): a + b = 1$, ta tìm được:

$$\begin{cases} a = \dfrac{1}{4} \\[4pt] b = \dfrac{3}{4} \\[4pt] c = \dfrac{7}{2} \end{cases} \implies H\left(\frac{1}{4}; \frac{3}{4}; \frac{7}{2}\right)$$

Suy ra $x_0 = \dfrac{1}{4}$ và $y_0 = \dfrac{3}{4}$. Giá trị biểu thức $P$ là:

$$P = x_0 - y_0 = \frac{1}{4} - \frac{3}{4} = \mathbf{-\frac{1}{2}}$$
Câu 12: Nhóm 1 Tâm tỉ cự & Lăng trụ

Cho hình lăng trụ tam giác đều $ABC.DEF$, $AB = 6, AD = 2$. Gọi $M, N, P$ lần lượt là trung điểm $DE, DF, BC$. Lập hệ trục tọa độ $Oxyz$ như hình. Điểm $S$ thỏa $\vec{SA} + 2\vec{SB} + \vec{SC} = \vec{0}$. Tính khoảng cách từ $S$ đến mặt phẳng $(MNP)$.

Hệ trục Oxyz theo đề bài lăng trụ ABC.DEF Gốc P(0;0;0)
Mặt phẳng $(MNP)$ Điểm $S$ & khoảng cách $SH$

• Chiều cao tam giác đều $ABC$: $PA = \frac{6\sqrt{3}}{2} = 3\sqrt{3}$, $PB = PC = 3$.

• Theo hệ trục tọa độ đã dựng trong đề:

  • Gốc $P(0;0;0)$, $A(3\sqrt{3}; 0; 0)$, $B(0; 3; 0)$, $C(0; -3; 0)$
  • Đỉnh trên: $D(3\sqrt{3}; 0; 2), E(0; 3; 2), F(0; -3; 2)$
  • Trung điểm: $M\left(\frac{3\sqrt{3}}{2}; \frac{3}{2}; 2\right)$, $N\left(\frac{3\sqrt{3}}{2}; -\frac{3}{2}; 2\right)$

• Mặt phẳng $(MNP)$ đi qua gốc $P(0;0;0)$ có VTPT là $\vec{n} = (4; 0; -3\sqrt{3})$:

$$(MNP): 4x - 3\sqrt{3}z = 0$$

• Xác định tọa độ $S$: Từ $\vec{SA} + 2\vec{SB} + \vec{SC} = \vec{0} \iff 4\vec{PS} = \vec{PA} + 2\vec{PB} + \vec{PC}$.

Vì $P$ là trung điểm $BC$ nên $\vec{PB} + \vec{PC} = \vec{0} \implies 4\vec{PS} = \vec{PA} + \vec{PB} \implies S\left(\frac{3\sqrt{3}}{4}; \frac{3}{4}; 0\right)$.

• Khoảng cách từ điểm $S$ đến mặt phẳng $(MNP)$:

$$d(S, (MNP)) = \frac{\left|4\cdot\frac{3\sqrt{3}}{4} - 3\sqrt{3}(0)\right|}{\sqrt{4^2 + 0^2 + (-3\sqrt{3})^2}} = \frac{3\sqrt{3}}{\sqrt{16 + 27}} = \mathbf{\frac{3\sqrt{129}}{43}}$$
